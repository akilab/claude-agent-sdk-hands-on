Lesson 08 / Agent SDK

Optionsと権限を設定する

Lesson 08では、`ClaudeAgentOptions` を使ってAgentの作業範囲とツール権限を設計します。 読み取り専用Agentを作り、`allowed_tools`、`disallowed_tools`、`permission_mode` の違いを手で確認します。

所要時間 60分
ゴール 実行前の確認 初出APIの見方 Optionsの読み方 権限フロー図 処理の流れ 読み取り専用Agentを書く 実行して確認 確認問題

Goal

このレッスンのゴール

このレッスンを一言で `ClaudeAgentOptions` で、Agentに許可する作業範囲とツール権限を設計します。

  • `allowed_tools` は「ツールを自動承認する設定」であり、それだけでは完全な制限ではないと説明できる
  • `disallowed_tools` で使わせたくないツールを明示できる
  • `permission_mode="dontAsk"` を使い、未承認ツールを質問せず拒否する設定を書ける
  • `system_prompt`、`cwd`、`max_turns` を組み合わせて、Agentの作業範囲を読み取り専用に寄せられる
  • 読み取り専用Agentで教材ファイルを読み、結果を `outputs/` に保存できる

Before run

実行前の確認

Lesson 08は、Lesson 06とLesson 07で使った `claude-agent-sdk` と同じ環境で動かします。 `python-labs/` で次の確認が通る状態にしてください。

Windows / macOS / Linux 
uv run python -c "import claude_agent_sdk; print('claude_agent_sdk OK')"
このレッスンで扱う権限は安全性に直結します

`allowed_tools`、`disallowed_tools`、`permission_mode` は、Agentがツールをどう使えるかに影響します。 実務では、最初から広い権限を渡すのではなく、必要な読み取りや確認から小さく始めます。

SDK concepts

初めて出てくる設定の見方

このレッスンで中心になるのは、`ClaudeAgentOptions` の引数です。 関数やクラスの分類だけでなく、各設定が「Agentの振る舞い」「ツール承認」「作業範囲」のどこに効くかを見ます。

名前 分類 インスタンス生成 Lesson 08での使い方
ClaudeAgentOptions クラス 必要。ClaudeAgentOptions(...) で設定オブジェクトを作る Agentの作業フォルダ、システムプロンプト、最大ターン数、ツール権限をまとめる。
query 関数 不要。呼び出して使う prompt と options を渡し、権限設定つきでAgentを実行する。
AssistantMessage クラス 不要。SDKから返ってくる Agentの途中応答やツール利用を表示する。
ResultMessage クラス 不要。SDKから返ってくる 実行完了状態、ターン数、セッションID、最終結果を表示する。

`allowed_tools` や `permission_mode` は、Pythonの関数ではなく `ClaudeAgentOptions` に渡す引数です。 つまり、個別に呼び出すものではなく、Agentを起動する前に「この条件で動いてください」と設定するものです。

Options detail

読み取り専用AgentのOptionsを読む

今回の実習では、Agentに教材ファイルを読ませます。 ただし、ファイル編集やコマンド実行は不要です。 そのため、読み取りに必要なツールだけを自動承認し、不要なツールを明示的に禁止します。

Lesson 08で使う設定 
options = ClaudeAgentOptions(
    cwd=str(PROJECT_ROOT),
    max_turns=4,
    system_prompt=(
        "あなたは社内文書の確認を支援するアシスタントです。"
        "ファイルの内容を読み、要点と注意点を簡潔に整理してください。"
        "ファイルの作成、編集、削除、コマンド実行は行いません。"
    ),
    allowed_tools=["Read", "Glob"],
    disallowed_tools=["Edit", "Write", "Bash"],
    permission_mode="dontAsk",
)
引数 Lesson 08での値 何を設定するか
cwd str(PROJECT_ROOT) Agentの基準フォルダです。今回のAgentは `python-labs/` を基準にファイルを探します。
max_turns 4 Agentic loopの上限です。ファイルを探して読み、整理する程度なら小さめで十分です。
system_prompt 社内文書確認アシスタントとしての前提 Agentの役割と禁止方針を先に固定します。毎回の依頼文ではなく、動作の前提として扱います。
allowed_tools ["Read", "Glob"] `Read` と `Glob` を自動承認します。これは「この2つだけが存在する」という意味ではありません。
disallowed_tools ["Edit", "Write", "Bash"] 編集、書き込み、コマンド実行を禁止します。使わせたくないツールは明示的に閉じます。
permission_mode "dontAsk" 未承認のツールを、ユーザーに質問せず拒否します。固定されたツール面にしたいときに使います。
`allowed_tools` だけで読み取り専用になるわけではありません

公式ドキュメントでは、`allowed_tools` は指定ツールを自動承認する設定として説明されています。 未指定のツールが完全に消えるわけではなく、権限モードや承認処理へ回る可能性があります。 読み取り専用に寄せたい場合は、`disallowed_tools` と `permission_mode="dontAsk"` も合わせて考えます。

権限設定の流れを図で見る

Before coding

コードを書く前に処理の流れを読む

Lesson 08のコードは、Agentを動かす前に教材ファイルとOptionsを準備します。 Pythonスクリプト自身がファイルを作る処理と、Agentがファイルを読む処理を分けて読むのがポイントです。

  1. `prepare_policy_file()` でAgentに読ませる教材ファイルを用意する
  2. `build_options()` で読み取り専用に寄せたOptionsを作る
  3. `build_prompt()` で、読む対象ファイルと整理形式を指定する
  4. `query(prompt=..., options=...)` でAgentを呼び出す
  5. `AssistantMessage` なら本文やツール名を表示する
  6. `ResultMessage` なら完了状態、ターン数、セッションIDを表示する
  7. 表示した内容を `outputs/lesson_08_permission_review.txt` に保存する

Hands-on

読み取り専用Agentを書く

`python-labs/practice/lesson_08_options_permissions.py` を作り、次のコードを入力してください。 基本は自分で書いて理解しますが、詰まった場合はコピーして進めても構いません。

python-labs/data/lesson_08_policy.txt 
社内FAQ公開ルール

- 公開前に法務チームが表現を確認する。
- 顧客名、個人情報、契約金額はFAQに掲載しない。
- 未確定の仕様は「予定」と明記する。
- 公開後の修正依頼はサポートチームが受け付ける。
- 緊急の修正は開発チームと法務チームの両方に連絡する。
python-labs/practice/lesson_08_options_permissions.py 
import asyncio

from claude_agent_sdk import (
    AssistantMessage,
    ClaudeAgentOptions,
    ResultMessage,
    query,
)

from shared.display import print_section
from shared.files import write_text_lines
from shared.messages import append_result_message, print_assistant_message
from shared.paths import PROJECT_ROOT


POLICY_PATH = PROJECT_ROOT / "data" / "lesson_08_policy.txt"
OUTPUT_PATH = PROJECT_ROOT / "outputs" / "lesson_08_permission_review.txt"


POLICY_TEXT = """
社内FAQ公開ルール

- 公開前に法務チームが表現を確認する。
- 顧客名、個人情報、契約金額はFAQに掲載しない。
- 未確定の仕様は「予定」と明記する。
- 公開後の修正依頼はサポートチームが受け付ける。
- 緊急の修正は開発チームと法務チームの両方に連絡する。
""".strip()


# Agentが読むための教材ファイルを用意する関数です。
def prepare_policy_file() -> None:
    POLICY_PATH.parent.mkdir(parents=True, exist_ok=True)
    POLICY_PATH.write_text(POLICY_TEXT + "\n", encoding="utf-8")


# 読み取り専用Agentとして動かすためのOptionsを作る関数です。
def build_options() -> ClaudeAgentOptions:
    return ClaudeAgentOptions(
        cwd=str(PROJECT_ROOT),
        max_turns=4,
        system_prompt=(
            "あなたは社内文書の確認を支援するアシスタントです。"
            "ファイルの内容を読み、要点と注意点を簡潔に整理してください。"
            "ファイルの作成、編集、削除、コマンド実行は行いません。"
        ),
        allowed_tools=["Read", "Glob"],
        disallowed_tools=["Edit", "Write", "Bash"],
        permission_mode="dontAsk",
    )


# Agentに依頼するプロンプトを作る関数です。
def build_prompt() -> str:
    relative_path = POLICY_PATH.relative_to(PROJECT_ROOT)
    return f"""
`{relative_path}` を読んで、次の形式で日本語で整理してください。

1. 重要なルール
2. 公開前に確認すべき注意点
3. 担当チームごとの見るべきポイント

ファイルの変更やコマンド実行は不要です。
""".strip()


# queryを呼び出し、読み取り専用設定でAgentを動かす関数です。
async def run_agent() -> None:
    prepare_policy_file()
    options = build_options()
    prompt = build_prompt()
    output_lines = []

    print_section("Policy file")
    print(POLICY_PATH)

    print_section("Prompt")
    print(prompt)

    print_section("Agent output")
    async for message in query(
        prompt=prompt,
        options=options,
    ):
        if isinstance(message, AssistantMessage):
            print_assistant_message(message, output_lines)
        elif isinstance(message, ResultMessage):
            print_section("Result")
            append_result_message(message, output_lines)

    write_text_lines(OUTPUT_PATH, output_lines)

    print_section("Saved output")
    print(f"Saved: {OUTPUT_PATH}")


# 非同期のrun_agent関数をイベントループで実行する関数です。
def main() -> None:
    asyncio.run(run_agent())


if __name__ == "__main__":
    main()

Review

確認問題

  1. `allowed_tools` だけでは完全なツール制限にならない理由を説明してください。
  2. `permission_mode="dontAsk"` を使うと、未承認ツールはどう扱われますか。
  3. `disallowed_tools=["Edit", "Write", "Bash"]` は何を防ぐための設定ですか。
  4. `cwd` を `python-labs/` に固定する理由を説明してください。
  5. 実務で `bypassPermissions` を安易に使うべきでない理由を説明してください。

Optionsと権限を設計できると、Agentに任せる範囲を明確にできます。 次のLesson 09では、実行結果をより扱いやすくするための構造化出力とログを扱います。
