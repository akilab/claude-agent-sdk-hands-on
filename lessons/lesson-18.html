Lesson 18 / ClaudeSDKClient

SQLiteでテーブルを作成する

Lesson 17で設計した `users`、`sessions`、`messages` を、実際のSQLiteデータベースとして作成します。 Agent実行コードはまだ書かず、DBを作る準備コードだけに集中します。

所要時間 50分
ゴール Agentと分ける理由 保存場所 テーブル定義 処理の流れ コードを書く 実行して確認 確認問題

Goal

このレッスンのゴール

このレッスンを一言で Agentを動かさず、後続レッスンで使う `data/agent_sessions.sqlite3` に3つのテーブルを作ります。

  • Python標準ライブラリの `sqlite3` でDBファイルを作成できる
  • `CREATE TABLE IF NOT EXISTS` の役割を説明できる
  • `users`、`sessions`、`messages` の3テーブルを作成できる
  • 作成済みテーブルを `sqlite_master` と `PRAGMA table_info` で確認できる

Separation

Agentコードとは分けて作る

この回ではClaude Agent SDKを実行しません。 DB作成とAgent実行を同じコードに入れると、学習者は「DB接続」「テーブル定義」「Agentへの問い合わせ」「レスポンス処理」を同時に読むことになります。 それでは主役がぼやけるため、まずDBの箱だけを独立して作ります。

今回作るもの

作るのはSQLiteファイルと3つのテーブルだけです。 ユーザーやメッセージの保存、`session_id` の登録、`resume` との接続は次のレッスン以降に回します。

Database path

DBはdataフォルダに置く

今回作るDBはLesson 18だけの出力ではありません。 Lesson 19以降で、セッション台帳や会話本文を保存するために継続して使います。 そのため、実行結果置き場の `outputs/` ではなく、共有データ置き場の `python-labs/data/agent_sessions.sqlite3` に作成します。

場所 役割 今回の扱い
python-labs/data/ 後続レッスンでも使う共有データ agent_sessions.sqlite3 を作る
python-labs/outputs/ 各レッスンの実行結果やログ 今回はDB本体を置かない

Schema

3つのテーブルを作る

SQLiteでは、テーブルの形をSQL文で定義します。 今回は `CREATE TABLE IF NOT EXISTS` を使い、すでにテーブルがある場合は作成をスキップできるようにします。

テーブル 主な列 ポイント
users user_id, status status で現在状態を持つ
sessions user_id, claude_session_id, title, cwd Claude側のIDは claude_session_id として保存する
messages claude_session_id, role, content, turn_number 会話本文や結果ログのように増え続ける情報を置く
NULLを避ける設計に寄せます

`last_resumed_at` は、まだresumeしていない状態を空文字で表します。 実務ではNULLを使う設計も一般的ですが、この教材では「値がない状態」を読みやすくするため、まずNOT NULL中心で進めます。

すでにDBを作っていた場合

`CREATE TABLE IF NOT EXISTS` は既存テーブルの列を作り直しません。 以前の版で `users.created_at` や `users.updated_at` を含むDBを作っていた場合は、DB Browserを閉じてから `data/agent_sessions.sqlite3` を削除し、このレッスンをもう一度実行してください。

Sequence

処理の流れを見る

`main()` がDBへ接続し、3つの `CREATE TABLE` を順番に実行し、最後に作成済みテーブルを確認します。 この流れは次回以降の保存処理からも呼び出しやすい形です。

Hands-on

コードを書く

`python-labs/practice/lesson_18_create_sqlite_tables.py` に、次のコードを入力してください。 Python標準ライブラリの `sqlite3` だけを使うため、追加インストールは不要です。

python-labs/practice/lesson_18_create_sqlite_tables.py 
import sqlite3
from typing import Any

from shared.display import print_section
from shared.paths import DATA_DIR


DATABASE_PATH = DATA_DIR / "agent_sessions.sqlite3"


# 後続レッスンでも使うSQLiteファイルへ接続する関数です。
def connect_database() -> sqlite3.Connection:
    DATA_DIR.mkdir(parents=True, exist_ok=True)
    connection = sqlite3.connect(DATABASE_PATH)
    connection.execute("PRAGMA foreign_keys = ON")
    return connection


# アプリ側のユーザーを保存するusersテーブルを作る関数です。
def create_users_table(connection: sqlite3.Connection) -> None:
    connection.execute(
        """
        CREATE TABLE IF NOT EXISTS users (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            user_id TEXT NOT NULL UNIQUE,
            status TEXT NOT NULL DEFAULT 'active'
                CHECK (status IN ('active', 'disabled', 'deleted'))
        )
        """
    )


# Claude Agent SDKのsession_idを、ユーザーごとの会話一覧として保存するsessionsテーブルを作る関数です。
def create_sessions_table(connection: sqlite3.Connection) -> None:
    connection.execute(
        """
        CREATE TABLE IF NOT EXISTS sessions (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            user_id TEXT NOT NULL,
            claude_session_id TEXT NOT NULL UNIQUE,
            title TEXT NOT NULL,
            cwd TEXT NOT NULL,
            created_at TEXT NOT NULL,
            updated_at TEXT NOT NULL,
            last_resumed_at TEXT NOT NULL DEFAULT '',
            FOREIGN KEY (user_id) REFERENCES users (user_id)
        )
        """
    )


# 各セッションに紐づく会話本文や結果ログを保存するmessagesテーブルを作る関数です。
def create_messages_table(connection: sqlite3.Connection) -> None:
    connection.execute(
        """
        CREATE TABLE IF NOT EXISTS messages (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            claude_session_id TEXT NOT NULL,
            role TEXT NOT NULL
                CHECK (role IN ('user', 'assistant', 'result', 'system')),
            content TEXT NOT NULL,
            turn_number INTEGER NOT NULL,
            created_at TEXT NOT NULL,
            FOREIGN KEY (claude_session_id) REFERENCES sessions (claude_session_id)
        )
        """
    )


# 3つのCREATE TABLEをまとめて実行し、最後に保存を確定する関数です。
def create_schema(connection: sqlite3.Connection) -> None:
    create_users_table(connection)
    create_sessions_table(connection)
    create_messages_table(connection)
    connection.commit()


# SQLite内に作成済みのテーブル名を確認する関数です。
def list_tables(connection: sqlite3.Connection) -> list[str]:
    rows = connection.execute(
        """
        SELECT name
        FROM sqlite_master
        WHERE type = 'table'
          AND name NOT LIKE 'sqlite_%'
        ORDER BY name
        """
    ).fetchall()
    return [row[0] for row in rows]


# 1つのテーブルについて、列名、型、NOT NULL、主キーなどの情報を確認する関数です。
def describe_table(
    connection: sqlite3.Connection,
    table_name: str,
) -> list[dict[str, Any]]:
    rows = connection.execute(f"PRAGMA table_info({table_name})").fetchall()
    return [
        {
            "name": row[1],
            "type": row[2],
            "not_null": bool(row[3]),
            "default": row[4],
            "primary_key": bool(row[5]),
        }
        for row in rows
    ]


# 作成したテーブルと列を、ターミナルで読みやすく表示する関数です。
def print_database_summary(connection: sqlite3.Connection) -> None:
    print_section("Database")
    print(DATABASE_PATH)

    table_names = list_tables(connection)
    print_section("Tables")
    for table_name in table_names:
        print(f"- {table_name}")

    print_section("Columns")
    for table_name in table_names:
        print(f"[{table_name}]")
        for column in describe_table(connection, table_name):
            required = "required" if column["not_null"] else "optional"
            primary = " primary_key" if column["primary_key"] else ""
            default = f" default={column['default']}" if column["default"] is not None else ""
            print(f"- {column['name']} {column['type']} {required}{primary}{default}")


# このファイルを直接実行したときの入口になる関数です。
def main() -> None:
    with connect_database() as connection:
        create_schema(connection)
        print_database_summary(connection)


if __name__ == "__main__":
    main()

Run

実行して確認

`python-labs/` から実行します。

Windows / macOS / Linux 
uv run python practice/lesson_18_create_sqlite_tables.py

正常に動くと、`Database`、`Tables`、`Columns` が表示されます。 `Tables` に `messages`、`sessions`、`users` が出ていれば成功です。

Windows

test -f data/agent_sessions.sqlite3 && echo exists

Review

確認問題

  1. 今回のDBファイルを `outputs/` ではなく `data/` に置く理由は何ですか。
  2. なぜAgent実行コードとDB作成コードを分けるのですか。
  3. `CREATE TABLE IF NOT EXISTS` は何を避けるための指定ですか。
  4. `sessions.id` と `sessions.claude_session_id` はどう違いますか。
  5. `messages` テーブルに本文を置く理由を説明してください。
