Lesson 06EX / Refactoring

共通関数へ整理する

Lesson 06では、最初のAgentを理解するために表示、保存、メッセージ処理を同じファイルに書きました。 ここでは周辺処理を共通関数へ分け、以降のレッスンでSDKの重要部分が見えやすい形に整えます。

所要時間 35分
ゴール やること フォルダの使い分け 共通化するもの 共有モジュール 整理後のLesson 06 実行して確認 確認問題

Goal

このレッスンのゴール

このレッスンを一言で 表示・保存・基本メッセージ処理を共通化し、各レッスンではSDKの主役だけが目立つ形にします。

  • `scripts/` と `scripts/shared/` の役割を説明できる
  • 共通化してよい処理と、各レッスンに残すべきSDK処理を分けられる
  • `shared` から共通関数をimportできる
  • 整理後のLesson 06で、`query()` と `ClaudeAgentOptions` が読みやすく残っていることを確認できる

What you will do

このレッスンでやろうとしていること

Lesson 06で見たコードには、表示、保存、メッセージ処理など、毎回似た形で出てくる処理が含まれています。 この補足回では、それらを `scripts/shared/` に分ける理由を整理します。

共通化の目的はコードを短く見せることだけではありません。 Agent SDKの学習ポイントであるOptions、query、メッセージ型、Skill、サブエージェントが埋もれないように、周辺処理を脇へ寄せるためです。

Folder rule

フォルダの使い分け

以降は、完成済みの実行ファイルを `scripts/` に置きます。 学習者はまず完成コードを実行し、動作を確認してから、必要な部分だけソースを読みます。

python-labsの構成 
python-labs/
  scripts/
    lesson_06_first_agent.py        # レッスンで実行する完成コード
    shared/                         # 完成版スクリプトからimportする共通関数
      display.py                    # 表示の共通関数
      files.py                      # 保存の共通関数
      messages.py                   # メッセージ処理の共通関数
      logs.py                       # 実行ログの共通関数
      paths.py                      # PROJECT_ROOTなどの共通パス
共有コードは `shared/` として置きます

共有コードは `scripts/shared/` にまとめます。 各レッスンの完成コードは `python-labs/` から `uv run python scripts/...` として実行するため、同じ `from shared...` で共通関数を読み込めます。

Refactoring policy

何を共通化し、何を残すか

教材では、共通化しすぎると学習ポイントが隠れます。 そのため、便利な周辺処理だけを共通化し、SDKの主役は各レッスンに残します。

扱い 対象 理由
共通化する print_section() 毎回同じ見出し表示で、SDK理解の主役ではないため。
共通化する テキスト保存、JSON保存、実行ログ生成 保存処理が長くなると、Agent SDKの設定が見えにくくなるため。
共通化する 基本的な AssistantMessage 表示 多くのレッスンで同じ処理を使うため。ただしLesson 07の詳細解析は各レッスン側に残す。
残す ClaudeAgentOptions(...) 権限、ターン数、Skill、サブエージェントなど、各レッスンの学習ポイントだから。
残す query(...) と async for Agent SDKをPythonから呼び出す中心部分だから。
残す output_format、AgentDefinition、skills レッスンごとに意味が違い、隠すと学習効果が落ちるため。

Shared modules

共有モジュールを読む

共有モジュールは、SDKの理解を邪魔しない範囲に絞ります。 まず、Lesson 6以降でよく使うimportの形を見ます。

共通関数のimport 
from shared.display import print_section
from shared.files import write_text_lines
from shared.messages import print_assistant_message, result_message_lines
from shared.paths import PROJECT_ROOT

`messages.py` の基本は、`AssistantMessage.content` から `text` や `name` を取り出して表示する処理です。 詳細なcontent block解析はLesson 07で扱うため、ここでは共通表示に必要な範囲だけにしています。

Hands-on

整理後のLesson 06を見る

`python-labs/scripts/lesson_06_first_agent.py` は完成版です。 必要に応じて、完成コードを読みながら処理の分け方を確認します。

python-labs/scripts/lesson_06_first_agent.py 
import asyncio

from claude_agent_sdk import (
    AssistantMessage,
    ClaudeAgentOptions,
    ResultMessage,
    query,
)

from shared.display import print_section
from shared.files import write_text_lines
from shared.messages import print_assistant_message, result_message_lines
from shared.paths import PROJECT_ROOT


OUTPUT_PATH = PROJECT_ROOT / "outputs" / "lesson_06_agent_output.txt"


MEETING_MEMO = """
社内FAQページの公開に向けて打ち合わせを行った。
公開日は来月第2週を目標にする。
営業チームは、よくある質問を10件選ぶ。
法務チームは、公開前に表現を確認する。
開発チームは、検索しやすいページ構成を検討する。
""".strip()


# Agentに依頼する内容を、会議メモつきで組み立てる関数です。
def build_prompt() -> str:
    return f"""
あなたは業務メモを整理するアシスタントです。
次の会議メモを、決定事項とTODOに分けて日本語で整理してください。
TODOは担当チームが分かるようにしてください。

会議メモ:
{MEETING_MEMO}

制約:
- ファイルを読まないでください。
- ファイルを変更しないでください。
- コマンドを実行しないでください。
- 短く、初学者にも分かる言葉で整理してください。
""".strip()


# 最初のAgentを安全に小さく動かすためのOptionsを作る関数です。
def build_options() -> ClaudeAgentOptions:
    return ClaudeAgentOptions(
        cwd=str(PROJECT_ROOT),
        max_turns=2,
        disallowed_tools=["Read", "Glob", "Edit", "Write", "Bash"],
    )


# queryを呼び出し、Agentから届くメッセージを順番に処理する関数です。
async def run_agent() -> None:
    options = build_options()
    prompt = build_prompt()
    output_lines = []

    print_section("Prompt")
    print(prompt)

    print_section("Agent output")
    async for message in query(
        prompt=prompt,
        options=options,
    ):
        if isinstance(message, AssistantMessage):
            print_assistant_message(message, output_lines)
        elif isinstance(message, ResultMessage):
            print_section("Result")
            lines = result_message_lines(
                message,
                include_turns=False,
                include_session=False,
            )
            for line in lines:
                print(line)
            output_lines.extend(lines)

    write_text_lines(OUTPUT_PATH, output_lines)

    print_section("Saved output")
    print(f"Saved: {OUTPUT_PATH}")


# 非同期のrun_agent関数をイベントループで実行する関数です。
def main() -> None:
    asyncio.run(run_agent())


if __name__ == "__main__":
    main()

Review

確認問題

  1. `scripts/` と `scripts/shared/` は、それぞれ何のために使いますか。
  2. なぜ `ClaudeAgentOptions` は共通関数に隠さず、各レッスンに残すのでしょうか。
  3. `print_section()` や `write_text_lines()` を共通化しても、学習効果が落ちにくい理由を説明してください。
  4. 完成コードをまず実行し、必要な部分だけ読む学習に変える理由を説明してください。

ここから先のレッスンでは、同じ表示・保存処理に邪魔されず、メッセージ、権限、構造化出力、Skills、サブエージェントの違いを見やすくしていきます。
