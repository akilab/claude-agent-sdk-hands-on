Lesson 15 / ClaudeSDKClient

session_idを保存する

`ResultMessage.session_id` を取り出し、アプリ側のJSON台帳に保存します。 SDKが持つセッションと、アプリが管理する会話一覧を分けて考えるためのレッスンです。

所要時間 60分
ゴール なぜ保存するか 初出APIの見方 保存するJSON 処理の流れ コードを書く 実行して確認 確認問題

Goal

このレッスンのゴール

このレッスンを一言で SDKから返る `session_id` を、自分のアプリが後で使える形で保存します。

  • `ResultMessage.session_id` はSDKが返す会話識別子だと説明できる
  • アプリ側で `user_id` と `session_id` を対応づける理由を説明できる
  • `cwd` を保存しておく意味を説明できる
  • 次のレッスンで `resume` に渡せるJSON台帳を作れる

Why save

なぜ `session_id` を保存するのか

`ClaudeSDKClient` は、同じclientインスタンス内ではセッションを自動的に続けます。 しかし、プロセスを終了した後や、複数ユーザー相当の会話を扱う場合は、 アプリ側が「どのユーザーが、どのセッションを続けるのか」を覚えておく必要があります。

管理するもの 持ち主 用途
会話履歴そのもの Agent SDK Claudeが過去の文脈を持って応答するため。
session_id Agent SDKから返る値 特定の過去セッションを `resume` するため。
user_id と session_id の対応 自分のアプリ 会話一覧、再開、ユーザーごとの分離のため。
cwd 自分のアプリ 同じ作業ディレクトリのセッションを再開するため。
保存するのは「会話の場所を指すID」です

`session_id` は会話履歴そのものではありません。 「後でこの会話へ戻るための識別子」です。 チャットUIやWebアプリでは、これをユーザーや会話タイトルと一緒に保存します。

SDK concepts

初めて出てくる関数・クラス・属性

今回はSDKの新しい大きなクラスは増えません。 主役は `ResultMessage.session_id` と、アプリ側で台帳を作るPythonコードです。

名前 分類 生成・呼び出し このレッスンでの役割

JSON shape

保存するJSONの形

今回は、次のような台帳を作ります。 `session_id` だけを裸で保存するのではなく、誰の会話か、どの作業ディレクトリの会話か、最後の状態はどうだったかを一緒に保存します。

この台帳はSDKの内部保存ではありません

SDKはセッション履歴を自動的にディスクへ保存します。 ここで作るJSONは、それとは別に「自分のアプリが会話を一覧・再開するための控え」です。

Sequence

処理の流れ

`session_id` は自分で作る値ではありません。 応答の最後に届く `ResultMessage` から読み取り、自分の台帳へ保存します。

Hands-on

コードを書く

`python-labs/practice/lesson_15_capture_session_id.py` に、次のコードを入力してください。 JSON台帳を扱うため、Pythonの辞書、リスト、ファイル読み書きも復習します。

python-labs/practice/lesson_15_capture_session_id.py 
import asyncio
import json
from datetime import datetime, timezone
from typing import Any

from claude_agent_sdk import (
    AssistantMessage,
    ClaudeAgentOptions,
    ClaudeSDKClient,
    ResultMessage,
)

from shared.display import print_section
from shared.files import write_json_file, write_text_lines
from shared.messages import append_result_message, print_assistant_message
from shared.paths import OUTPUT_DIR, PROJECT_ROOT


USER_ID = "learner-001"
CONVERSATION_TITLE = "ClaudeSDKClient session capture"
SESSION_REGISTRY_PATH = OUTPUT_DIR / "lesson_15_session_registry.json"
TRANSCRIPT_PATH = OUTPUT_DIR / "lesson_15_session_transcript.txt"

PROMPT = (
    "Claude Agent SDKをPythonで学ぶ人に向けて、"
    "セッションIDを保存する理由を3文で説明してください。"
)


# UTCの現在時刻を、JSONに保存しやすい文字列にする関数です。
def now_iso() -> str:
    return datetime.now(timezone.utc).isoformat()


# ClaudeSDKClientに渡す実行設定を作る関数です。
def build_options() -> ClaudeAgentOptions:
    return ClaudeAgentOptions(
        cwd=str(PROJECT_ROOT),
        system_prompt=(
            "あなたはClaude Agent SDKを学ぶ日本語教材の補助者です。"
            "短く、実務に結びつけて説明してください。"
        ),
        disallowed_tools=["Read", "Glob", "Grep", "Write", "Edit", "Bash"],
        max_turns=2,
    )


# 既存のセッション台帳JSONを読み込む関数です。
def load_registry() -> dict[str, Any]:
    if not SESSION_REGISTRY_PATH.exists():
        return {
            "version": 1,
            "updated_at": now_iso(),
            "sessions": [],
        }

    return json.loads(SESSION_REGISTRY_PATH.read_text(encoding="utf-8"))


# セッション台帳に保存する1件分の辞書を作る関数です。
def build_session_entry(result_message: ResultMessage) -> dict[str, Any]:
    return {
        "user_id": USER_ID,
        "title": CONVERSATION_TITLE,
        "session_id": result_message.session_id,
        "cwd": str(PROJECT_ROOT),
        "last_subtype": result_message.subtype,
        "is_error": result_message.is_error,
        "num_turns": result_message.num_turns,
        "created_at": now_iso(),
        "updated_at": now_iso(),
    }


# 同じuser_idの古い記録を置き換え、台帳を最新状態にする関数です。
def upsert_session_entry(
    registry: dict[str, Any],
    entry: dict[str, Any],
) -> dict[str, Any]:
    sessions = registry.get("sessions", [])
    kept_sessions = [
        session
        for session in sessions
        if session.get("user_id") != entry["user_id"]
    ]

    registry["version"] = 1
    registry["updated_at"] = now_iso()
    registry["sessions"] = [*kept_sessions, entry]
    return registry


# Agentからの1回分の応答を最後まで読み、ResultMessageを取り出す関数です。
async def receive_response(
    client: ClaudeSDKClient,
) -> tuple[ResultMessage | None, list[str]]:
    result_message = None
    output_lines: list[str] = []

    async for message in client.receive_response():
        if isinstance(message, AssistantMessage):
            print_assistant_message(message, output_lines)
        elif isinstance(message, ResultMessage):
            result_message = message
            append_result_message(message, output_lines, include_result=False)

    return result_message, output_lines


# ClaudeSDKClientで問い合わせ、ResultMessage.session_idを台帳へ保存する関数です。
async def capture_session_id() -> None:
    print_section("Prompt")
    print(PROMPT)

    async with ClaudeSDKClient(options=build_options()) as client:
        await client.query(PROMPT)
        result_message, transcript_lines = await receive_response(client)

    if result_message is None:
        raise RuntimeError("ResultMessageを受け取れなかったため、session_idを保存できません。")

    session_entry = build_session_entry(result_message)
    registry = upsert_session_entry(load_registry(), session_entry)

    write_json_file(SESSION_REGISTRY_PATH, registry)
    write_text_lines(TRANSCRIPT_PATH, transcript_lines)

    print_section("Saved session")
    print(f"user_id: {session_entry['user_id']}")
    print(f"session_id: {session_entry['session_id']}")
    print(f"registry: {SESSION_REGISTRY_PATH}")
    print(f"transcript: {TRANSCRIPT_PATH}")


# このファイルを直接実行したときの入口になる関数です。
def main() -> None:
    asyncio.run(capture_session_id())


if __name__ == "__main__":
    main()

Review

確認問題

  1. `session_id` は自分で作る値ですか、SDKから受け取る値ですか。
  2. `session_id` だけでなく `user_id` を一緒に保存する理由を説明してください。
  3. `cwd` が変わると、なぜ `resume` 時に問題になり得ますか。
  4. SDKが保存する会話履歴と、今回作ったJSON台帳の違いを説明してください。
  5. この台帳をWebアプリで使う場合、DBに置き換えるとしたらどの列が必要ですか。
