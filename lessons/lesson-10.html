Lesson 10 / Extension

Agent Skillsを設計する

Lesson 10では、繰り返し使う判断基準やレビュー手順をSkillとして外出しします。 Pythonコードに長い指示を埋め込むのではなく、`.claude/skills/<name>/SKILL.md` に置いた手順をAgent SDKから読み込ませます。

所要時間 65分
ゴール やること 実行前の確認 初出APIの見方 SKILL.mdの読み方 シーケンス図 処理の流れ Skillを読み込んで使う 実行して確認 確認問題

Goal

このレッスンのゴール

このレッスンを一言で `.claude/skills/` に置いた `SKILL.md` を、`skills` オプションでAgentに使わせます。

  • SkillはPython関数ではなく、ファイルシステム上の `SKILL.md` であると説明できる
  • Project Skillの置き場所 `.claude/skills/<name>/SKILL.md` を説明できる
  • `setting_sources=["project"]` がProject Skillの検出に関係することを説明できる
  • `skills=["faq-review"]` と `skills="all"` の違いを説明できる
  • Skillの `description` が、Claudeが使う場面を判断する手がかりだと理解できる

What you will do

このレッスンでやろうとしていること

Skillsは、Python関数ではなく、Agentに読み込ませる手順書です。 このレッスンでは、`.claude/skills/.../SKILL.md` を作り、Agentがその内容を参照して回答する流れを確認します。

完成コードでは、`setting_sources`、`skills`、Skillファイルの配置、特定Skillの有効化を観察します。 業務ルールやレビュー観点をコードに埋め込まず、外部の手順として管理する考え方を学びます。

Before run

実行前の確認

Lesson 10も `python-labs/` のuv環境で動かします。 このレッスンでは、先に `python-labs/.claude/skills/faq-review/SKILL.md` を作成し、その後Pythonコードから読み込ませます。

Windows / macOS / Linux 
uv run python -c "import claude_agent_sdk; print('claude_agent_sdk OK')"
Skillはサンドボックスではありません

公式ドキュメントでは、`skills` オプションはコンテキストフィルタであり、サンドボックスではないと説明されています。 Skillを絞っても、ファイル自体はディスク上に残ります。ツール権限は `allowed_tools`、`disallowed_tools`、`permission_mode` で別に設計します。

SDK concepts

初めて出てくる設定とファイル

Lesson 10の主役は、Pythonの新しい関数ではなく、Agent SDKが読み込むファイルシステム設定です。 Skillは「呼び出す関数」ではなく、Claudeが必要なときに読む専門手順として考えます。

名前 分類 インスタンス生成 Lesson 10での使い方
SKILL.md Markdownファイル 不要。ファイルとして作成する 専門手順、判断基準、説明をMarkdownで書く。SDKに登録するPython APIはない。
description YAML frontmatterの項目 不要。文字列として書く Claudeが「このSkillを使うべき場面か」を判断するための説明。
setting_sources ClaudeAgentOptions の引数 不要。リストを渡す "project" を含めると、プロジェクトの `.claude/` 設定を読み込む。
skills ClaudeAgentOptions の引数 不要。リスト、"all"、または [] を渡す 今回のセッションで使えるSkillを絞る。指定するとSDKがSkill toolを有効化する。
SDK の Agent Skills SDK で Claude Code 機能を使用する Python SDK reference
`skills="all"` と `skills=["faq-review"]` は形が違います

検出されたすべてのSkillを有効にする場合は、文字列で `skills="all"` と書きます。 特定のSkillだけを有効にする場合は、Skill名のリストで `skills=["faq-review"]` と書きます。 `skills=["all"]` は「all」という名前のSkillを指定する形になり得るため、全Skill有効化とは別物です。

Skill file

`SKILL.md` を作成する

Skillは、YAML frontmatterとMarkdown本文を持つファイルです。 `name` はSkillの名前、`description` はClaudeが使うタイミングを判断する説明、本文は実際の手順です。

まず `python-labs/.claude/skills/faq-review/` フォルダを作り、その中に `SKILL.md` を作成します。 Pythonコードの中でSkill本文を生成しないため、Agentを動かすコードは短く読みやすくなります。

PowerShell 
New-Item -ItemType Directory -Force .claude/skills/faq-review
macOS / Linux 
mkdir -p .claude/skills/faq-review

`python-labs/.claude/skills/faq-review/SKILL.md` に、次の内容を確認します。

python-labs/.claude/skills/faq-review/SKILL.md 
---
name: faq-review
description: 社内FAQやサポート記事の公開前レビューで、表現の明確さ、リスク、担当チームの次アクションを確認するときに使います。
---

# FAQレビューSkill

あなたは、社内FAQ原稿を公開前に確認するレビュー担当です。

このSkillが関連する場合は、次の観点で確認します。

1. FAQの目的を日本語で短く要約する。
2. 断定が強すぎる表現や、誤解を招きそうな表現を見つける。
3. 担当チームごとの次アクションを分けて整理する。
4. ビジネス向けポータルに適した、慎重で具体的な言い換えを提案する。
5. 回答は簡潔に、見出しつきで整理する。
`description` は厳密な条件式ではありません

`description` は、ClaudeがSkillの利用場面を判断するための自然言語の説明です。 「この単語が入ったら必ず起動」のようなif文ではありません。曖昧な説明にすると、期待した場面で使われないことがあります。

Sequence

Skillが使われる順番を図で見る

`Options` は実行主体ではありません。 `run_agent()` が `query(prompt, options)` を呼び、Agent loopの中でClaudeが必要だと判断したときにSkill toolが `SKILL.md` を読みます。

Before coding

完成コードを動かす前に処理の流れを読む

Lesson 10では、Pythonコード、Skillファイル、Agent SDKの設定が分かれます。 関係を先に整理してから完成コードを読むと、似た形の `query()` でも目的が見えます。

  1. 事前に `.claude/skills/faq-review/SKILL.md` を作る
  2. `ensure_skill_file()` がSkillファイルの存在を確認する
  3. `build_options()` が `setting_sources=["project"]` と `skills=["faq-review"]` を設定する
  4. `build_prompt()` がFAQ原稿とレビュー依頼を作る
  5. `query(prompt=..., options=...)` でAgentを起動する
  6. Claudeが依頼内容とSkillの `description` を見て、必要ならSkillを使う
  7. `AssistantMessage` と `ResultMessage` を読み、レビュー結果を保存する

Hands-on

Skillを読み込んでAgentから使う

`python-labs/scripts/lesson_10_agent_skills.py` の完成コードを確認します。 今回のコードは、事前に作ったSkillファイルを確認し、Skillを有効化してAgentを呼ぶ処理だけを書きます。

python-labs/scripts/lesson_10_agent_skills.py 
import asyncio

from claude_agent_sdk import (
    AssistantMessage,
    ClaudeAgentOptions,
    ResultMessage,
    query,
)

from shared.display import print_section
from shared.files import write_text_lines
from shared.messages import append_result_message, print_assistant_message
from shared.paths import PROJECT_ROOT


SKILL_PATH = PROJECT_ROOT / ".claude" / "skills" / "faq-review" / "SKILL.md"
OUTPUT_PATH = PROJECT_ROOT / "outputs" / "lesson_10_skill_review.txt"


# Agentに確認してもらうFAQ原稿です。
# ファイルに保存せず、プロンプト内の文字列として渡します。
FAQ_DRAFT = """
FAQ: 新しい請求書ダウンロード機能について

Q. いつから請求書をダウンロードできますか？
A. 来月から必ず利用できます。

Q. 過去の請求書も確認できますか？
A. すべての過去請求書を確認できます。

Q. 問い合わせ先はどこですか？
A. 不明点はサポートチームへ連絡してください。
""".strip()


# Skillファイルが事前に作成されているか確認する関数です。
def ensure_skill_file() -> None:
    if SKILL_PATH.exists():
        return

    raise FileNotFoundError(
        "Skill file was not found. "
        "Create python-labs/.claude/skills/faq-review/SKILL.md first."
    )


# Agentに依頼するプロンプトを作る関数です。
def build_prompt() -> str:
    return f"""
faq-review Skillを使って、次の社内FAQ原稿を公開前レビューしてください。

確認してほしい観点:
- 断定が強すぎる表現
- 法務確認が必要そうな箇所
- 担当チームごとの次アクション
- より安全な言い換え

FAQ原稿:
{FAQ_DRAFT}
""".strip()


# Project Skillを読み込むためのOptionsを作る関数です。
def build_options() -> ClaudeAgentOptions:
    return ClaudeAgentOptions(
        cwd=str(PROJECT_ROOT),
        max_turns=4,
        # projectを含めると、cwd配下の .claude/skills/ が読み込まれます。
        setting_sources=["project"],
        # 今回は事前に用意したfaq-reviewだけを有効にします。
        # すべてのSkillを有効にしたい場合は、リストではなく skills="all" と書きます。
        # skills=["all"] は、「all」という名前のSkillを指定する形になり得るため別物です。
        skills=["faq-review"],
        # FAQ原稿はプロンプトに入れるので、ファイル読み書きやコマンド実行は不要です。
        disallowed_tools=["Read", "Glob", "Edit", "Write", "Bash"],
    )


# 事前に作成したSkillを有効化し、Agentを実行する関数です。
async def run_agent() -> None:
    ensure_skill_file()

    options = build_options()
    prompt = build_prompt()
    output_lines = []

    print_section("Skill file")
    print(SKILL_PATH)

    print_section("Prompt")
    print(prompt)

    print_section("Agent output")
    async for message in query(
        prompt=prompt,
        options=options,
    ):
        if isinstance(message, AssistantMessage):
            print_assistant_message(message, output_lines)
        elif isinstance(message, ResultMessage):
            append_result_message(message, output_lines)

    write_text_lines(OUTPUT_PATH, output_lines)

    print_section("Saved output")
    print(OUTPUT_PATH)


# 非同期のrun_agent関数をイベントループで実行する関数です。
def main() -> None:
    asyncio.run(run_agent())


if __name__ == "__main__":
    main()

確認問題

  1. SkillはPython関数ですか。それともファイルですか。
  2. Project Skillはどのフォルダに置きますか。
  3. `setting_sources=["project"]` は何を読み込むための設定ですか。
  4. `skills=["faq-review"]` と `skills="all"` の違いを説明してください。
  5. `skills` オプションがサンドボックスではない、とはどういう意味ですか。
