Lesson 11 / Extension

サブエージェントの役割を実装する

Lesson 11では、親Agentにすべてを背負わせず、専門のサブエージェントへ一部の判断を任せます。 `AgentDefinition` で役割を定義し、親Agentが `Agent` ツールを使ってレビュー担当へ依頼する流れを書きます。

所要時間 70分
ゴール 実行前の確認 初出APIの見方 AgentDefinitionの読み方 シーケンス図 処理の流れ サブエージェントを書く 実行して確認 確認問題

Goal

このレッスンのゴール

このレッスンを一言で `AgentDefinition` で専門役を定義し、親Agentから `Agent` ツールで呼び出します。

  • サブエージェントは「役割を持つ別Agent」であり、単なる関数呼び出しではないと説明できる
  • `AgentDefinition` の `description`、`prompt`、`tools`、`maxTurns` を説明できる
  • `ClaudeAgentOptions(agents=...)` でサブエージェントを登録できる
  • 親Agentがサブエージェントを使うには `Agent` ツールが必要だと説明できる
  • サブエージェントに渡す役割とツール権限を小さく設計できる

Before run

実行前の確認

Lesson 11も `python-labs/` のuv環境で動かします。 サブエージェントはSDKの機能なので、追加ファイルは不要です。

Windows / macOS / Linux 
uv run python -c "from claude_agent_sdk import AgentDefinition; print('AgentDefinition OK')"
サブエージェントにも権限設計が必要です

サブエージェントは便利ですが、何でも任せる相手ではありません。 今回はFAQ原稿を読むだけなので、サブエージェントの `tools=[]` とし、親Agentにも `Agent` 以外のツールを使わせません。

SDK concepts

初めて出てくる関数・クラス・設定

Lesson 11では、`AgentDefinition` が初登場します。 Lesson 10のSkillはファイルでしたが、サブエージェントはPythonコード内で役割定義を書きます。

名前 分類 インスタンス生成 Lesson 11での使い方
AgentDefinition SDKのクラス 必要。AgentDefinition(...) で作る サブエージェントの説明、専用プロンプト、使えるツール、最大ターン数を定義する。
agents ClaudeAgentOptions の引数 不要。辞書を渡す サブエージェント名と AgentDefinition を対応づけて親Agentへ渡す。
Agent SDK側のツール名 不要。文字列として権限に書く 親Agentがサブエージェントを呼び出すために使うツール。allowed_tools=["Agent"] で許可する。
maxTurns AgentDefinition の項目 不要。数値を渡す サブエージェント側のターン上限。ClaudeAgentOptions.max_turns とは名前の形が違う。
skills AgentDefinition の項目 不要。リストを渡す サブエージェント起動時に、指定したSkill内容を事前に読み込ませる。

Definition detail

`AgentDefinition` を読む

サブエージェントは、親Agentから呼び出される専門役です。 `description` は親Agentが使う場面を判断する手がかり、`prompt` はサブエージェント自身の役割指示です。

Lesson 11で使うAgentDefinition 
"faq-risk-reviewer": AgentDefinition(
    description=(
        "公開前の日本語FAQを読み、断定が強すぎる表現、"
        "未確定仕様、法務確認が必要そうな箇所をレビューします。"
    ),
    prompt=(
        "あなたは公開前FAQのリスクレビュー担当です。"
        "原稿を読み、断定が強すぎる表現、未確定に見える仕様、"
        "法務確認が必要そうな箇所、より安全な言い換えを日本語で整理してください。"
    ),
    tools=[],
    maxTurns=2,
)
項目 意味 今回の値
description 親Agentが、どのサブエージェントを使うべきか判断するための説明。 公開前FAQのリスクレビュー担当であることを説明。
prompt サブエージェント自身に与える役割指示。 断定表現、未確定仕様、法務確認、言い換えを確認するよう指示。
tools サブエージェントが使えるツール。 []。今回はプロンプト内の文章だけを読むため、ツールなし。
maxTurns サブエージェントのターン上限。 2。短いレビューに限定する。
`maxTurns` はcamelCaseです

`ClaudeAgentOptions` では `max_turns` を使いましたが、`AgentDefinition` では公式例に合わせて `maxTurns` を使います。 似た意味でも、クラスによって項目名の形が違う点に注意します。

サブエージェントは親のSkill利用状況をそのまま引き継ぎません

サブエージェントは新しい会話として起動します。 親Agentで使ったSkillの本文や、親の会話履歴が丸ごと渡るわけではありません。 サブエージェントにSkillを使わせたい場合は、`AgentDefinition` 側で明示します。

設定 意味 使う場面
skills=["faq-review"] サブエージェント起動時に、指定したSkillの内容を文脈へ事前投入する。 レビュー担当に、最初からレビュー手順を持たせたい場合。
tools=["Skill"] サブエージェントが実行中にSkill toolを呼び出せるようにする。 必要に応じてSkillを選ばせたい場合。
tools=[] サブエージェントにツールを使わせない。 今回のように、渡された文章だけを短くレビューさせたい場合。
サブエージェントにSkillを事前投入する例 
"faq-risk-reviewer": AgentDefinition(
    description="公開前FAQをレビューします。",
    prompt="あなたはFAQレビュー担当です。",
    tools=["Skill"],
    skills=["faq-review"],
    maxTurns=2,
)

Sequence

親Agentとサブエージェントの流れを図で見る

`AgentDefinition` は実行主体ではありません。 `run_agent()` がOptionsへサブエージェント定義を渡し、親Agentが `Agent` ツールで必要な仕事だけを依頼します。

Before coding

コードを書く前に処理の流れを読む

Lesson 11では、親Agentとサブエージェントの責務を分けます。 `query()` の形はこれまでと似ていますが、今回の主役は `agents` と `Agent` ツールです。

  1. `build_agents()` が `faq-risk-reviewer` サブエージェントを定義する
  2. `build_options()` が `agents=...` と `allowed_tools=["Agent"]` を設定する
  3. `build_prompt()` が親Agentへの依頼文を作る
  4. `query(prompt=..., options=...)` で親Agentを起動する
  5. 親Agentが必要だと判断したら、`Agent` ツールでサブエージェントへ依頼する
  6. サブエージェントのレビュー結果を親Agentがまとめる
  7. `ResultMessage` として完了状態を受け取り、出力を保存する

Hands-on

サブエージェントを書く

`python-labs/practice/lesson_11_subagents.py` を作り、次のコードを入力してください。 役割分担を学ぶため、サブエージェント定義、親AgentのOptions、プロンプトを分けて書きます。

python-labs/practice/lesson_11_subagents.py 
import asyncio

from claude_agent_sdk import (
    AgentDefinition,
    AssistantMessage,
    ClaudeAgentOptions,
    ResultMessage,
    query,
)

from shared.display import print_section
from shared.files import write_text_lines
from shared.messages import append_result_message, print_assistant_message
from shared.paths import PROJECT_ROOT


OUTPUT_PATH = PROJECT_ROOT / "outputs" / "lesson_11_subagent_review.txt"


# サブエージェントにレビューしてもらうFAQ原稿です。
# 今回も、教材を短く保つためファイルではなく文字列として渡します。
FAQ_DRAFT = """
FAQ: 請求書ダウンロード機能

Q. 新しい機能はいつ使えますか？
A. 来月から必ず全ユーザーが使えます。

Q. 過去の請求書も見られますか？
A. すべての過去請求書を確認できます。

Q. ダウンロードできない場合はどうしますか？
A. サポートチームに連絡してください。
""".strip()


# この実行で使うサブエージェント定義を作る関数です。
def build_agents() -> dict[str, AgentDefinition]:
    return {
        "faq-risk-reviewer": AgentDefinition(
            description=(
                "公開前の日本語FAQを読み、断定が強すぎる表現、"
                "未確定仕様、法務確認が必要そうな箇所をレビューします。"
            ),
            prompt=(
                "あなたは公開前FAQのリスクレビュー担当です。"
                "原稿を読み、断定が強すぎる表現、未確定に見える仕様、"
                "法務確認が必要そうな箇所、より安全な言い換えを日本語で整理してください。"
                "必要以上に長くせず、実務担当者が次に動ける形で答えてください。"
            ),
            # サブエージェントにツールを使わせない設定です。
            # 今回はプロンプトに入れた文章だけをレビューするため、ツールは不要です。
            tools=[],
            # AgentDefinitionでは、公式ドキュメントに合わせてmaxTurnsのようなcamelCaseを使います。
            maxTurns=2,
        ),
    }


# 親Agentに依頼するプロンプトを作る関数です。
def build_prompt() -> str:
    return f"""
faq-risk-reviewer サブエージェントを使って、次のFAQ原稿を公開前レビューしてください。

親Agentの役割:
- サブエージェントにレビューを依頼する
- 返ってきた指摘を、担当者が読みやすい形で短くまとめる

FAQ原稿:
{FAQ_DRAFT}
""".strip()


# サブエージェントを使うためのOptionsを作る関数です。
def build_options() -> ClaudeAgentOptions:
    return ClaudeAgentOptions(
        cwd=str(PROJECT_ROOT),
        max_turns=6,
        # Agent toolを許可すると、親Agentがサブエージェントを呼び出せます。
        allowed_tools=["Agent"],
        # 今回はファイル操作やコマンド実行は不要です。
        disallowed_tools=["Read", "Glob", "Edit", "Write", "Bash"],
        permission_mode="dontAsk",
        agents=build_agents(),
    )


# 親Agentを起動し、サブエージェントのレビュー結果を保存する関数です。
async def run_agent() -> None:
    options = build_options()
    prompt = build_prompt()
    output_lines = []

    print_section("Prompt")
    print(prompt)

    print_section("Agent output")
    async for message in query(
        prompt=prompt,
        options=options,
    ):
        if isinstance(message, AssistantMessage):
            print_assistant_message(message, output_lines)
        elif isinstance(message, ResultMessage):
            append_result_message(message, output_lines)

    write_text_lines(OUTPUT_PATH, output_lines)

    print_section("Saved output")
    print(OUTPUT_PATH)


# 非同期のrun_agent関数をイベントループで実行する関数です。
def main() -> None:
    asyncio.run(run_agent())


if __name__ == "__main__":
    main()

Tool: Agent

1. 注意すべき表現

Review

確認問題

  1. Skillとサブエージェントの違いを説明してください。
  2. `AgentDefinition.description` と `AgentDefinition.prompt` は、それぞれ誰のための情報ですか。
  3. 親Agentがサブエージェントを呼ぶために、なぜ `allowed_tools=["Agent"]` が必要ですか。
  4. 今回、サブエージェントの `tools=[]` にした理由を説明してください。
  5. `max_turns` と `maxTurns` の違いに注意すべき理由を説明してください。
