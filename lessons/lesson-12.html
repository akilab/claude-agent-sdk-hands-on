Lesson 12 / Business

業務向けミニ自動化を完成させる

Lesson 12では、ここまで学んだ要素を一つの小さな業務フローにまとめます。 Skillでレビュー観点を持たせ、サブエージェントに専門レビューを任せ、親Agentが構造化出力と実行ログとして保存します。

所要時間 80分
ゴール 実行前の確認 組み合わせる要素 完成形の読み方 シーケンス図 処理の流れ 自動化コードを書く 実行して確認 確認問題

Goal

このレッスンのゴール

このレッスンを一言で Skill、サブエージェント、構造化出力を組み合わせ、FAQ公開前レビューの小さな業務自動化を完成させます。

  • Skill、サブエージェント、構造化出力の役割分担を説明できる
  • サブエージェントに `skills=["faq-review"]` を指定する意味を説明できる
  • 親Agentに `allowed_tools=["Agent"]` を設定する理由を説明できる
  • 最終結果を `ResultMessage.structured_output` から受け取り、JSONとして保存できる
  • 業務利用前に、入力、判断基準、権限、出力、ログを分けて確認できる

Before run

実行前の確認

Lesson 12は、Lesson 10で作成した `faq-review` Skillを使います。 先に `python-labs/.claude/skills/faq-review/SKILL.md` があることを確認してください。

Windows / macOS / Linux 
uv run python -c "from claude_agent_sdk import AgentDefinition; print('AgentDefinition OK')"

Skillファイルも確認します。

PowerShell 
Get-Content .claude/skills/faq-review/SKILL.md
macOS / Linux 
cat .claude/skills/faq-review/SKILL.md
最終回でも、権限は小さく保ちます

このレッスンでは、親Agentには `Agent` ツールだけを許可します。 FAQ原稿はPython文字列として渡すため、`Read`、`Write`、`Bash` は不要です。 業務自動化では、便利さより先に「何を許すか」を明確にします。

SDK concepts

このレッスンで組み合わせる要素

Lesson 12では新しいSDKの主役を増やすのではなく、すでに学んだ要素を業務フローとして接続します。 似たコードに見えても、今回の目的は「部品をつなぐ設計」です。

名前 分類 インスタンス生成 Lesson 12での役割
SKILL.md Markdownファイル 不要。Lesson 10で作ったファイルを使う FAQレビューの観点を、Pythonコードから切り離した判断基準として使う。
AgentDefinition.skills AgentDefinition の項目 不要。リストを渡す サブエージェント起動時に、`faq-review` Skillの内容を事前に読み込ませる。
allowed_tools=["Agent"] ClaudeAgentOptions の設定 不要。リストを渡す 親Agentがサブエージェントを呼び出せるようにする。ファイル操作やコマンド実行は許可しない。

ResultMessage.structured_output ResultMessage の属性 不要。SDKから返る結果が持つ スキーマに合う最終結果を直接取り出し、JSONファイルに保存する。

Architecture

完成形の読み方

今回のPythonコードは長く見えますが、責務は五つに分かれます。 どの関数が何をしているかを先に分けると、業務自動化の設計として読みやすくなります。

責務 関数・定義 何を担当するか
入力 FAQ_DRAFT レビュー対象のFAQ原稿。今回はファイルではなくPython文字列として渡す。
判断基準 SKILL.md / ensure_skill_file() レビュー観点が存在するか確認する。Skill本文はPythonコード内に埋め込まない。
専門レビュー build_agents() `faq-risk-reviewer` サブエージェントを定義し、`faq-review` Skillを事前投入する。
実行制御 build_options() 親Agentの権限、サブエージェント、構造化出力をまとめる。
出力保存 save_outputs() レビュー結果と実行ログを別々のJSONファイルとして保存する。
今回は親Agentとサブエージェントの責務を分けます

サブエージェントはFAQをレビューする専門役です。 親Agentは、サブエージェントの指摘を受け取り、公開判断、リスク、次アクションという業務で扱いやすい形にまとめます。

Sequence

完成形の流れを図で見る

`Options` や `AgentDefinition` は、実行主体ではありません。 実行の起点は `run_agent()` で、`query()` が親Agentを動かし、親Agentが `Agent` ツールでサブエージェントを呼びます。

Before coding

コードを書く前に処理の流れを読む

最終回では、関数の順番を追うことがとても大事です。 どの関数も小さな責務を持ち、`run_agent()` がそれらを組み合わせます。

  1. `main()` が `asyncio.run(run_agent())` で非同期処理を起動する
  2. `run_agent()` が `ensure_skill_file()` でSkillファイルの存在を確認する
  3. `build_options()` が `build_agents()` を呼び、`faq-risk-reviewer` を登録する
  4. `AgentDefinition.skills=["faq-review"]` により、サブエージェントへレビュー観点を事前投入する
  5. `build_prompt()` が親Agentへの依頼文とFAQ原稿を作る
  6. `query(prompt=..., options=...)` が親Agentを実行する
  7. 親Agentが `Agent` ツールでサブエージェントへレビューを依頼する
  8. `ResultMessage.structured_output` から構造化データを取り出す
  9. `save_outputs()` がレビュー結果と実行ログを保存する

Hands-on

業務向けミニ自動化を書く

`python-labs/practice/lesson_12_business_automation.py` を作り、次のコードを入力してください。 長いコードですが、入力、Skill確認、サブエージェント定義、Options、構造化出力、ログ保存を分けて読むと整理できます。

python-labs/practice/lesson_12_business_automation.py 
import asyncio
import json

from claude_agent_sdk import (
    AgentDefinition,
    AssistantMessage,
    ClaudeAgentOptions,
    ResultMessage,
    query,
)

from shared.display import print_section
from shared.files import write_json_file
from shared.logs import build_run_log
from shared.messages import print_assistant_message
from shared.paths import OUTPUT_DIR, PROJECT_ROOT


SKILL_PATH = PROJECT_ROOT / ".claude" / "skills" / "faq-review" / "SKILL.md"
STRUCTURED_OUTPUT_PATH = OUTPUT_DIR / "lesson_12_release_review.json"
RUN_LOG_PATH = OUTPUT_DIR / "lesson_12_run_log.json"


# 最終レッスンでは、公開前FAQの小さな業務自動化を作ります。
# 入力はPython内の文字列、判断基準はLesson 10で作ったSkill、
# 専門レビューはLesson 11で学んだサブエージェント、
# 最終出力はLesson 09で学んだ構造化出力として保存します。
FAQ_DRAFT = """
FAQ: 請求書ダウンロード機能

Q. 新しい機能はいつ使えますか？
A. 来月から必ず全ユーザーが使えます。

Q. 過去の請求書も見られますか？
A. すべての過去請求書を確認できます。

Q. ダウンロードに失敗した場合はどうしますか？
A. サポートチームに連絡してください。

Q. 請求書データはどのくらい保存されますか？
A. 保存期間は現在確認中です。
""".strip()


# Agentに最終的に作ってほしいJSONのイメージです。
#
# {
#   "summary": "レビュー全体の短い要約",
#   "release_readiness": "ready / needs_changes / blocked のどれか",
#   "risk_items": [
#     {
#       "area": "リスクの領域",
#       "issue": "問題になりそうな表現や内容",
#       "recommendation": "修正案や確認案",
#       "owner": "次に確認すべき担当"
#     }
#   ],
#   "next_actions": [
#     {
#       "team": "担当チーム",
#       "action": "次に行う作業",
#       "priority": "high / medium / low のどれか"
#     }
#   ],
#   "subagent_used": true
# }
#
# OUTPUT_SCHEMAは、上のJSONをClaudeに返してもらうための設計図です。
# 「文章をあとからPythonでJSON化する」のではなく、
# Agent SDKの構造化出力としてResultMessage.structured_outputに入る形を指定します。
OUTPUT_SCHEMA = {
    "type": "object",
    "properties": {
        "summary": {
            "type": "string",
            "description": "公開前レビュー全体の短い要約",
        },
        "release_readiness": {
            "type": "string",
            "enum": ["ready", "needs_changes", "blocked"],
            "description": "現時点の公開判断",
        },
        "risk_items": {
            "type": "array",
            "items": {
                "type": "object",
                "properties": {
                    "area": {"type": "string"},
                    "issue": {"type": "string"},
                    "recommendation": {"type": "string"},
                    "owner": {"type": "string"},
                },
                "required": ["area", "issue", "recommendation", "owner"],
            },
            "description": "公開前に確認すべきリスク項目",
        },
        "next_actions": {
            "type": "array",
            "items": {
                "type": "object",
                "properties": {
                    "team": {"type": "string"},
                    "action": {"type": "string"},
                    "priority": {
                        "type": "string",
                        "enum": ["high", "medium", "low"],
                    },
                },
                "required": ["team", "action", "priority"],
            },
            "description": "公開前に行う次アクション",
        },
        "subagent_used": {
            "type": "boolean",
            "description": "faq-risk-reviewerサブエージェントを使ったかどうか",
        },
    },
    "required": [
        "summary",
        "release_readiness",
        "risk_items",
        "next_actions",
        "subagent_used",
    ],
}


# Lesson 10で作ったSkillファイルがあるか確認する関数です。
def ensure_skill_file() -> None:
    if SKILL_PATH.exists():
        return

    raise FileNotFoundError(
        "Skill file was not found. "
        "Create python-labs/.claude/skills/faq-review/SKILL.md first."
    )


# この業務自動化で使うサブエージェント定義を作る関数です。
def build_agents() -> dict[str, AgentDefinition]:
    return {
        "faq-risk-reviewer": AgentDefinition(
            description=(
                "公開前の日本語FAQを読み、断定が強すぎる表現、"
                "未確定仕様、法務確認が必要そうな箇所をレビューします。"
            ),
            prompt=(
                "あなたは公開前FAQのリスクレビュー担当です。"
                "faq-review Skillの観点を使い、断定表現、未確定仕様、"
                "法務確認、担当チームの次アクションを日本語で整理してください。"
                "親Agentが構造化出力へまとめやすいよう、根拠を短く明確にしてください。"
            ),
            # skillsにSkill名を指定すると、サブエージェント起動時にそのSkill内容を読み込ませます。
            # tools=[]なので、サブエージェントは実行中にファイル操作やコマンド実行をしません。
            skills=["faq-review"],
            tools=[],
            maxTurns=3,
        ),
    }


# 親Agentに依頼するプロンプトを作る関数です。
def build_prompt() -> str:
    return f"""
faq-risk-reviewer サブエージェントを使って、次のFAQ原稿を公開前レビューしてください。

必ず行うこと:
- faq-risk-reviewer にレビューを依頼する
- 返ってきた指摘を、公開判断、リスク、次アクションに整理する
- 最終回答は指定されたJSON Schemaに合う構造化出力にする
- subagent_used は true にする

FAQ原稿:
{FAQ_DRAFT}
""".strip()


# 親AgentのOptionsを作る関数です。
def build_options() -> ClaudeAgentOptions:
    return ClaudeAgentOptions(
        cwd=str(PROJECT_ROOT),
        max_turns=8,
        # projectを含めると、python-labs/.claude/skills/ が検出対象になります。
        setting_sources=["project"],
        # 親Agentには、サブエージェントを呼ぶAgent toolだけを許可します。
        allowed_tools=["Agent"],
        # 今回は教材を安全に保つため、ファイル操作やコマンド実行は使わせません。
        disallowed_tools=["Read", "Glob", "Edit", "Write", "Bash"],
        permission_mode="dontAsk",
        agents=build_agents(),
        # output_formatは、最終結果をResultMessage.structured_outputで受け取るための設定です。
        output_format={
            "type": "json_schema",
            "schema": OUTPUT_SCHEMA,
        },
    )


# 親Agentを起動し、サブエージェントの結果を構造化JSONとして保存する関数です。
async def run_agent() -> None:
    ensure_skill_file()

    options = build_options()
    prompt = build_prompt()
    final_result = None
    structured_output = None

    print_section("Skill file")
    print(SKILL_PATH)

    print_section("Prompt")
    print(prompt)

    print_section("Agent output")
    async for message in query(
        prompt=prompt,
        options=options,
    ):
        if isinstance(message, AssistantMessage):
            print_assistant_message(message)
        elif isinstance(message, ResultMessage):
            final_result = message
            structured_output = message.structured_output

    if final_result is None:
        raise RuntimeError("ResultMessage was not received.")

    run_log = build_run_log(final_result, structured_output)

    if structured_output is not None:
        write_json_file(STRUCTURED_OUTPUT_PATH, structured_output)
    write_json_file(RUN_LOG_PATH, run_log)

    print_section("Structured output")
    if structured_output is None:
        print("No structured output was returned.")
    else:
        print(json.dumps(structured_output, ensure_ascii=False, indent=2))

    print_section("Saved files")
    print(STRUCTURED_OUTPUT_PATH)
    print(RUN_LOG_PATH)


# 非同期のrun_agent関数をイベントループで実行する関数です。
def main() -> None:
    asyncio.run(run_agent())


if __name__ == "__main__":
    main()

Review

確認問題

  1. このレッスンで、Skill、サブエージェント、構造化出力はそれぞれ何を担当していますか。
  2. サブエージェントに `skills=["faq-review"]` を指定する理由を説明してください。
  3. 親Agentに `allowed_tools=["Agent"]` だけを許可している理由を説明してください。
  4. `ResultMessage.structured_output` と `ResultMessage.subtype` の役割の違いを説明してください。
  5. このミニ自動化を実務で使う前に、どの入力、権限、出力、ログを確認しますか。
