Lesson 05 / Python

async / await の感覚をつかむ

Agent SDKのPythonサンプルでは、非同期処理と `async for` が登場します。 このレッスンではSDKを呼ぶ前に、待つ処理、順番に流れるメッセージ、並行実行の感覚をPythonだけで練習します。

所要時間 40分
ゴール 今回使うPython 非同期の流れを動かす 実行して読み解く 確認問題

Goal

このレッスンのゴール

このレッスンを一言で Agent SDKで必須になる非同期処理を、async / await / async for の流れとして理解します。

  • `async def` が非同期関数を定義する構文だと説明できる
  • `await` が「待てる処理の完了を待つ」ための構文だと説明できる
  • `async for` で、少しずつ届く結果を順に処理できる
  • `asyncio.gather()` で複数の処理を並行して待てる
  • Agent SDKの `query()` を読む準備ができる

Python concepts

今回使うPython

Coroutine async def

すぐに結果を返さず、イベントループの中で進む処理を定義します。

Await await

待ち時間のある処理を、他の処理を止めすぎずに待ちます。

Stream async for

Agentから少しずつ届くメッセージのような流れを順に受け取ります。

Hands-on

非同期の流れを動かす

`python-labs/scripts/lesson_05_async_basics.py` の完成コードを確認します。 ここではAgentの代わりに、少しずつメッセージを返す処理を自分で作ります。

python-labs/scripts/lesson_05_async_basics.py 
import asyncio
from datetime import datetime


LESSON_STEPS = [
    "入力を確認する",
    "必要なファイルを読む",
    "Agentに渡す文脈を組み立てる",
    "結果を保存する",
]


# 現在時刻をログに表示しやすい文字列にする関数です。
def now_text() -> str:
    return datetime.now().strftime("%H:%M:%S")


# 見出しを区切り線つきで表示する関数です。
def print_section(title: str) -> None:
    print()
    print("=" * 72)
    print(title)
    print("=" * 72)


# 指定した秒数だけ待ち、処理完了メッセージを返す非同期関数です。
async def wait_for_step(step_name: str, seconds: float) -> str:
    print(f"[{now_text()}] start: {step_name}")
    await asyncio.sleep(seconds)
    print(f"[{now_text()}] done : {step_name}")
    return f"{step_name} が完了しました"


# Agentのように、メッセージを少しずつ返す非同期ジェネレータ関数です。
async def stream_agent_like_messages(topic: str):
    messages = [
        f"{topic} の目的を確認しています",
        "関連する入力を読み取っています",
        "回答の下書きを組み立てています",
        "最終結果を返します",
    ]

    for message in messages:
        await asyncio.sleep(0.3)
        yield message


# awaitを使って、複数の処理を順番に待つ関数です。
async def run_steps_in_order() -> None:
    print_section("await: 順番に待つ")

    for step_name in LESSON_STEPS:
        result = await wait_for_step(step_name, 0.2)
        print(f"result: {result}")


# async forを使って、少しずつ届くメッセージを読む関数です。
async def run_stream() -> None:
    print_section("async for: 少しずつ届く結果を読む")

    async for message in stream_agent_like_messages("Lesson 05"):
        print(f"message: {message}")


# asyncio.gatherを使って、複数の処理を並行して待つ関数です。
async def run_steps_in_parallel() -> None:
    print_section("asyncio.gather: 複数の確認を並行して待つ")

    tasks = [
        wait_for_step("Python環境を確認する", 0.5),
        wait_for_step("学習ログを確認する", 0.3),
        wait_for_step("次のレッスンを確認する", 0.4),
    ]

    results = await asyncio.gather(*tasks)

    print()
    print("Parallel results:")
    for result in results:
        print(f"- {result}")


# Lesson 05の非同期処理を順番に実行する関数です。
async def main_async() -> None:
    print("Claude Agent SDK Hands-on / Lesson 05")
    await run_steps_in_order()
    await run_stream()
    await run_steps_in_parallel()


# 非同期のmain_async関数をイベントループで実行する関数です。
def main() -> None:
    asyncio.run(main_async())


if __name__ == "__main__":
    main()
