Lesson 02 / Foundation

uvでPythonプロジェクトを作る

このレッスンでは、教材用の `python-labs/` をuvプロジェクトとして初期化します。 `pyproject.toml`、`.venv`、`uv.lock` の役割を理解し、最後にプロジェクト状態を確認するPythonスクリプトを書きます。

所要時間 35分
ゴール なぜ最小構成で作るか uvプロジェクトを作る Pythonで状態を確認する 確認問題

Goal

このレッスンのゴール

このレッスンを一言で uvでPython実習環境を作り、依存関係と仮想環境を教材内で再現できる状態にします。

  • `python-labs/` をuvプロジェクトとして初期化できる
  • `pyproject.toml` が何を管理するファイルか説明できる
  • `.venv` が作られるタイミングと、Gitに入れない理由を説明できる
  • `uv.lock` をGitに入れる理由を説明できる
  • プロジェクト状態を確認するPythonスクリプトを書ける

Project shape

なぜ最小構成で作るか

uvの通常の `uv init` は、新しいプロジェクト用に `.git/`、`.gitignore`、`.python-version`、`README.md`、 `main.py`、`pyproject.toml` を作ります。今回はすでに学習サイトのGitリポジトリ内に `python-labs/` があるため、 その中に別のGitリポジトリや不要なサンプルファイルを作らない構成にします。

公式ドキュメントでは、最小構成にしたい場合は `--bare` を使うと `pyproject.toml` だけを作れると説明されています。 この教材では、既存のフォルダ構成を保つために `uv init --bare` を使います。

この教材での方針

実習で自由に書き換える `scripts/` はGit対象外にしています。一方で、依存関係を再現するための `pyproject.toml` と `uv.lock` はGitに入れる前提で扱います。

Hands-on

uvプロジェクトを作る

まず、教材リポジトリのルートから `python-labs/` に移動します。 すでにLesson 01のスクリプトを実行している場合は、`python-labs/` にいるかもしれません。

PowerShell 
cd python-labs

次に、既存フォルダを最小構成のuvプロジェクトとして初期化します。 `--bare` は余計なファイルを作らないための指定です。

PowerShell 
uv init --bare --name agent-sdk-learning

`pyproject.toml` が作成されたら、中身を確認します。

PowerShell 
Get-Content pyproject.toml

表示される内容はuvやPythonのバージョンによって少し変わりますが、おおむね次の形になります。

pyproject.toml 
[project]
name = "agent-sdk-learning"
version = "0.1.0"
requires-python = ">=3.10"
dependencies = []
`requires-python` は自分の環境に合わせて確認します

uvが生成する `requires-python` は、手元のPythonバージョンに影響されることがあります。 この教材はPython 3.10以上を前提にするため、必要に応じて `requires-python = ">=3.10"` に調整してください。

この段階で `uv run` を使ってPythonを実行します。公式ドキュメントでは、最初の `uv run`、`uv sync`、 `uv lock` のタイミングで仮想環境と `uv.lock` が作られると説明されています。

PowerShell 
uv run python --version

ここで `.venv/` が作られても正常です。`.venv/` は依存パッケージやPython実行環境を入れる作業用フォルダなので、 サイズが大きく、利用者の環境差も出ます。そのため、このリポジトリでは `.gitignore` で除外しています。

まだAgent SDKは呼び出しませんが、依存関係の管理を体験するために公式クイックスタートと同じパッケージを追加します。 ネットワークに接続できる環境で実行してください。

PowerShell 
uv add claude-agent-sdk

`uv add` の後に `pyproject.toml` をもう一度見ると、`dependencies` に `claude-agent-sdk` が追加されます。 さらに `uv.lock` には、実際に解決された正確な依存関係が記録されます。

Hands-on

Pythonで状態を確認する

`python-labs/scripts/lesson_02_check_uv_project.py` の完成コードを確認します。 このスクリプトでは、`Path`、関数、リスト、簡単な文字列検索を使って、uvプロジェクトの状態を確認します。

python-labs/scripts/lesson_02_check_uv_project.py 
from pathlib import Path


PROJECT_ROOT = Path(__file__).resolve().parents[1]
PYPROJECT_PATH = PROJECT_ROOT / "pyproject.toml"
LOCK_PATH = PROJECT_ROOT / "uv.lock"
VENV_PATH = PROJECT_ROOT / ".venv"


# 見出しを区切り線つきで表示する関数です。
def print_section(title: str) -> None:
    print()
    print("=" * 72)
    print(title)
    print("=" * 72)


# テキストファイルを読み込み、行のリストとして返す関数です。
def read_text_lines(path: Path) -> list[str]:
    if not path.exists():
        return []

    text = path.read_text(encoding="utf-8")
    return text.splitlines()


# 指定した文字列で始まる行を探し、見つからなければNoneを返す関数です。
def find_line(lines: list[str], starts_with: str) -> str | None:
    for line in lines:
        stripped = line.strip()
        if stripped.startswith(starts_with):
            return stripped

    return None


# 複数行の中に指定したキーワードが含まれるか確認する関数です。
def contains_text(lines: list[str], keyword: str) -> bool:
    for line in lines:
        if keyword in line:
            return True

    return False


# pyproject.tomlがあり、基本項目が書かれているか確認する関数です。
def check_pyproject() -> bool:
    print_section("pyproject.toml")

    if not PYPROJECT_PATH.exists():
        print(f"NG: {PYPROJECT_PATH} was not found.")
        print("Run: uv init --bare --name agent-sdk-learning")
        return False

    lines = read_text_lines(PYPROJECT_PATH)
    name_line = find_line(lines, "name =")
    python_line = find_line(lines, "requires-python =")
    has_dependency = contains_text(lines, "claude-agent-sdk")

    print(f"OK: found {PYPROJECT_PATH}")
    print(f"Project name: {name_line or 'not found'}")
    print(f"Python requirement: {python_line or 'not found'}")

    if has_dependency:
        print("OK: claude-agent-sdk is listed in dependencies.")
    else:
        print("INFO: claude-agent-sdk is not listed yet.")
        print("Run it when you are ready: uv add claude-agent-sdk")

    return name_line is not None and python_line is not None


# uv.lockが作成されているか確認する関数です。
def check_lockfile() -> bool:
    print_section("uv.lock")

    if LOCK_PATH.exists():
        print(f"OK: found {LOCK_PATH}")
        print("This file records exact dependency versions.")
        return True

    print("INFO: uv.lock was not found yet.")
    print("Run: uv run python --version")
    return False


# .venvが作成されているか確認する関数です。
def check_virtual_environment() -> bool:
    print_section(".venv")

    if VENV_PATH.exists():
        print(f"OK: found {VENV_PATH}")
        print(".venv is local to your machine and should not be committed.")
        return True

    print("INFO: .venv was not found yet.")
    print("uv can create it when you run a project command.")
    return False


# 学習用フォルダが揃っているか確認する関数です。
def check_learning_folders() -> bool:
    print_section("Learning folders")

    expected_dirs = [
        PROJECT_ROOT / "scripts",
        PROJECT_ROOT / "src" / "agent_sdk_learning",
        PROJECT_ROOT / "data",
        PROJECT_ROOT / "outputs",
    ]

    all_found = True
    for directory in expected_dirs:
        if directory.exists():
            print(f"OK: {directory.relative_to(PROJECT_ROOT)}")
        else:
            print(f"NG: missing {directory.relative_to(PROJECT_ROOT)}")
            all_found = False

    return all_found


# 各確認結果をOKまたは要確認としてまとめて表示する関数です。
def print_summary(results: dict[str, bool]) -> None:
    print_section("Summary")

    for label, ok in results.items():
        status = "OK" if ok else "要確認"
        print(f"{label}: {status}")


# Lesson 02の確認処理を順番に実行する関数です。
def main() -> None:
    print("Claude Agent SDK Hands-on / Lesson 02")
    print(f"Project root: {PROJECT_ROOT}")

    results = {
        "pyproject.toml": check_pyproject(),
        "uv.lock": check_lockfile(),
        ".venv": check_virtual_environment(),
        "learning folders": check_learning_folders(),
    }

    print_summary(results)


if __name__ == "__main__":
    main()

保存したら、`python-labs/` から実行します。

PowerShell 
uv run python scripts/lesson_02_check_uv_project.py

Review

確認問題

  1. 通常の `uv init` ではなく `uv init --bare` を使った理由を説明してください。
  2. `pyproject.toml` と `uv.lock` の役割の違いを1文ずつ書いてください。
  3. `.venv/` をGitに入れない理由を説明してください。
  4. `uv run` が実行前に確認してくれることは何ですか。
  5. `uv add claude-agent-sdk` を実行すると、どのファイルが更新されますか。
