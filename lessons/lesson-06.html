Lesson 06 / Agent SDK

最初のPython Agentを動かす

ここからClaude Agent SDKを実際に呼び出します。 Lesson 06では、ツールを使わない小さなAgentを作り、`query()` から届くメッセージを `async for` で表示します。

所要時間 50分
ゴール 実行前の確認 初出APIの見方 Optionsの読み方 処理の流れ 関数呼び出し図 最初のAgentを書く 実行して読み解く 確認問題

Goal

このレッスンのゴール

このレッスンを一言で `query()` を使って最小のPython Agentを起動し、最終結果を受け取ります。

  • `claude_agent_sdk` から `query()` を呼び出せる
  • `ClaudeAgentOptions` で作業フォルダ、ターン数、使わせないツールを設定できる
  • `async for` でAgentから届くメッセージを順番に読める
  • `AssistantMessage` と `ResultMessage` を分けて表示できる
  • 最初のAgentは、ツール利用よりも「Pythonから呼べた」流れを優先して確認できる

SDK concepts

初めて出てくるSDK部品の見方

ここで初めてClaude Agent SDKの部品が出てきます。 Pythonに慣れていない人にも読めるようにしますが、説明の粒度は実務でSDKを読むときに使える水準にします。 まず「これは関数なのか、クラスなのか」「自分でインスタンスを作るのか、SDKから返ってくるのか」「どの属性やメソッドを使うのか」を整理します。

名前 分類 インスタンス生成 Lesson 06での使い方
query 関数 不要。呼び出して使う prompt と options を渡し、Agentから届くメッセージの流れを async for で読む。
ClaudeAgentOptions クラス 必要。ClaudeAgentOptions(...) で設定オブジェクトを作る 作業フォルダ、最大ターン数、禁止ツールなどをまとめ、query に渡す。
AssistantMessage クラス 不要。SDKから返ってくる Claudeの途中応答を表す。isinstance で判定し、content を読む。
ResultMessage クラス 不要。SDKから返ってくる Agent実行の最終状態を表す。subtype や result を確認する。

重要なのは、`query()` が最終回答の文字列を1つ返す関数ではないことです。 SDKは、Agentが動いている間に複数のメッセージを順番に返します。 そのためコードでは、戻り値を普通の文字列として受け取るのではなく、`async for` で1件ずつ処理します。

query は関数です

`query` は、PythonコードからClaude Agent SDKへ依頼を送る入口です。 Lesson 06では、`query(prompt=prompt, options=options)` の形で呼び出します。 `prompt` にはAgentへ依頼する文字列、`options` には `ClaudeAgentOptions` のインスタンスを渡します。

項目 Lesson 06での値 意味
prompt str Agentへの依頼文です。今回は会議メモを整理する指示を渡します。
options ClaudeAgentOptions Agentの実行条件です。作業場所、最大ターン数、禁止ツールなどを指定します。
戻り値 非同期に読めるメッセージ列 AssistantMessage や ResultMessage などが順番に届きます。通常の for ではなく async for で読みます。

AssistantMessage と ResultMessage はSDKが返すクラスです

`AssistantMessage` と `ResultMessage` は、こちらが自分で作るためのクラスではなく、`query()` の実行中にSDKから返ってくるメッセージ型です。 そのため `AssistantMessage(...)` のようにインスタンスを生成する必要はありません。 コード側では、届いた `message` がどの型なのかを `isinstance(message, AssistantMessage)` のように判定して、型に応じて読む属性を変えます。

型 主に読む属性 Lesson 06での扱い
AssistantMessage content Claudeが途中で返した内容です。本文テキストだけでなく、ツール利用などの部品が含まれることがあります。
ResultMessage subtype, result subtype と result は、どちらも ResultMessage が持つ属性です。subtype の中に result が入っているわけではありません。subtype で完了状態を見て、message.result があれば最終結果テキストとして表示します。

`AssistantMessage.content` の中身は、単なる文字列ではなく「本文」「ツール利用」などのcontent blockのリストとして届きます。 Lesson 06のコードでは、content blockに `text` があれば本文として表示し、`name` があればツール名として表示します。 この構造はLesson 07でさらに詳しく読みます。

Options detail

ClaudeAgentOptionsは設定用のクラスです

`ClaudeAgentOptions` は、Agentの「作業場所」「使える道具」「実行量」「会話の続け方」などを決める設定です。 つまり、プロンプトが「何をしてほしいか」だとすると、`ClaudeAgentOptions` は「どの範囲で、どの条件で動いてよいか」を決める操作盤です。 これはクラスなので、`ClaudeAgentOptions(...)` と呼び出してインスタンスを生成し、そのインスタンスを `query()` の `options` 引数へ渡します。

Lesson 06で使う設定 
options = ClaudeAgentOptions(
    disallowed_tools=["Read", "Glob", "Edit", "Write", "Bash"],
    cwd=str(PROJECT_ROOT),
    max_turns=2,
)

この3つは、初回のAgent実行で特に大事です。 `cwd` で作業範囲を固定し、`max_turns` で長く走り続けることを防ぎ、`disallowed_tools` で今回は不要なツールを外します。 先に制約を小さくしておくと、エラーが出たときにも原因を追いやすくなります。

引数 型の目安 Lesson 06での値 何を設定するか
cwd str またはパス str(PROJECT_ROOT) Agentの基準フォルダです。相対パスの解釈、設定ファイルの読み込み、ツールが見る範囲の起点に影響します。
max_turns int 2 Agentic loopの上限です。回答の文字数ではなく、考える、必要ならツールを使う、結果を読む、という往復の上限です。
disallowed_tools list[str] ["Read", "Glob", "Edit", "Write", "Bash"] 指定したツールを禁止します。Lesson 06ではファイル読み取りや編集を使わせず、会議メモの文章整理だけに集中します。

`max_turns` は「回答の長さ」ではなく、Agentic loopの回数です。 ツールを使うAgentでは、調査、ツール実行、結果確認の往復が増えるため、上限が小さいと `error_max_turns` で終わることがあります。 そのためLesson 06では、ツールが不要な会議メモ整理にして、`max_turns=2` でも終わりやすくしています。

`allowed_tools` は「それだけに制限する」設定ではありません

`allowed_tools=["Read"]` と書くと、Readだけを使えるように見えますが、公式には「指定したツールを自動承認する」設定です。 未指定のツールが完全に消えるわけではありません。使わせたくないツールは `disallowed_tools` で明示します。 「Readだけを許可し、それ以外は聞かずに拒否したい」ような厳しい運用では、`allowed_tools` と `permission_mode="dontAsk"` を組み合わせる考え方が必要です。

今後よく使う設定も、用途ごとに見ておきます。ここでは暗記ではなく「どの場面で気にするか」をつかめれば十分です。

引数 主な用途 読み方
system_prompt Agentの役割や振る舞いを固定する 業務用Agentでは、回答の粒度、文体、判断基準、禁止事項をここに置きます。プロンプト本文に毎回混ぜるより、役割の前提として分けると保守しやすくなります。
allowed_tools 指定ツールを自動承認する 「このツールだけに制限する」ではありません。未指定のツールも、権限モードや承認処理に回る可能性があります。
permission_mode ツール承認の全体ルールを決める default、dontAsk、plan、acceptEdits、bypassPermissions などがあります。安全運用に直結するためLesson 08で扱います。
model 使用モデルを指定する 未指定なら環境やClaude Code側の既定に従います。教材では契約や環境差を吸収しやすいよう、最初は固定しません。
continue_conversation / resume 以前の会話を続ける continue_conversation は直近の会話を続け、resume はセッションIDを指定して再開します。Lesson 06では毎回新規実行にします。
max_budget_usd 推定コストの上限を置く クライアント側の推定コストが指定額に達したら停止します。Pro以上サブスクリプション前提でも、将来の扱い変更や業務利用を考えると重要な安全弁です。
include_partial_messages 途中断片を受け取る True にすると、完成したメッセージだけでなく途中の断片も受け取れます。進捗表示には便利ですが、処理が複雑になるため初回は扱いません。
設定を広げるときの例 
options = ClaudeAgentOptions(
    cwd=str(PROJECT_ROOT),
    max_turns=6,
    system_prompt="あなたは業務文書を読み、決定事項とTODOを正確に整理するアシスタントです。",
    allowed_tools=["Read", "Glob"],
    permission_mode="dontAsk",
)

この例では `Read` と `Glob` を自動承認し、`permission_mode="dontAsk"` によって未承認のツールは確認せず拒否します。 ファイルを読む必要があるLessonでは便利ですが、Lesson 06ではまだ使いません。 初回は、ツール許可よりも「Agentから返ってくるメッセージを読めるようになる」ことを優先します。

Lesson 06であえて使わない設定

`permission_mode`、`allowed_tools`、`system_prompt`、`model` などは便利ですが、最初から全部入れると何が効いているのか分かりにくくなります。 まずは `cwd`、`max_turns`、`disallowed_tools` の3つで、安全に小さく動かします。

Before coding

コードを書く前に処理の流れを読む

Lesson 06の処理は、上から順に見ると次の流れです。 初めてのSDKコードでは、細部の属性名を暗記するよりも、どの関数が呼び出し口で、どのクラスが設定で、どのクラスが結果なのかを分けて読むことが大切です。

  1. `build_prompt()` でAgentに依頼する文章を作る
  2. `ClaudeAgentOptions` で作業フォルダ、ターン数、使わせないツールを設定する
  3. `query(prompt=..., options=...)` でAgentを呼び出す
  4. `async for` で届いたメッセージを1件ずつ読む
  5. `AssistantMessage` なら途中応答として表示する
  6. `ResultMessage` なら最後の状態として表示する
  7. 表示した内容を `outputs/` に保存する
最初は細部より流れを優先します

このレッスンでは、SDKのメッセージ構造を完全に網羅しません。 ただし、初めて出てくる関数とクラスが「呼び出すもの」「設定として渡すもの」「SDKから返ってくるもの」のどれなのかは、ごまかさずに押さえます。 Lesson 07で、`AssistantMessage.content` と `ResultMessage` の中身をさらに詳しく読みます。

`error_max_turns` が出た場合

Agentが指定ターン数の中で終われなかった状態です。 最初の教材ではツール利用が増えると混乱しやすいため、Lesson 06はツールを使わないプロンプトにしています。 ファイル読み取りやツール利用は、メッセージ構造を理解した後のレッスンで扱います。

Function flow

関数が呼ばれる順番を図で見る

Lesson 06のコードは関数が多く見えますが、役割は大きく4つに分かれます。 `main()` は起動入口、`run_agent()` は全体の司令塔、`print_assistant_message()` と `print_result_message()` はメッセージ型ごとの表示、`save_output()` は最後の保存です。 まず関数同士の関係を見て、そのあと実行順をシーケンス図で確認します。

Hands-on

最初のAgentを書く

`python-labs/practice/lesson_06_first_agent.py` を作り、次のコードを入力してください。 最初のAgentなので、ファイル読み取り、編集、コマンド実行は避け、会議メモを整理してもらうだけに絞ります。 このコードでは、Agentに依頼する文を作り、返ってくるメッセージを順に表示し、最後に `outputs/` へ保存します。

まず、SDKから使う部品を読み込みます。

Python import 
from claude_agent_sdk import (
    AssistantMessage,
    ClaudeAgentOptions,
    ResultMessage,
    query,
)
python-labs/practice/lesson_06_first_agent.py 
import asyncio
from pathlib import Path

from claude_agent_sdk import (
    AssistantMessage,
    ClaudeAgentOptions,
    ResultMessage,
    query,
)


PROJECT_ROOT = Path(__file__).resolve().parents[1]
OUTPUT_PATH = PROJECT_ROOT / "outputs" / "lesson_06_agent_output.txt"


MEETING_MEMO = """
社内FAQページの公開に向けて打ち合わせを行った。
公開日は来月第2週を目標にする。
営業チームは、よくある質問を10件選ぶ。
法務チームは、公開前に表現を確認する。
開発チームは、検索しやすいページ構成を検討する。
""".strip()


# 見出しを区切り線つきで表示する関数です。
def print_section(title: str) -> None:
    print()
    print("=" * 72)
    print(title)
    print("=" * 72)


# Agentに依頼する内容を、会議メモつきで組み立てる関数です。
def build_prompt() -> str:
    return f"""
あなたは業務メモを整理するアシスタントです。
次の会議メモを、決定事項とTODOに分けて日本語で整理してください。
TODOは担当チームが分かるようにしてください。

会議メモ:
{MEETING_MEMO}

制約:
- ファイルを読まないでください。
- ファイルを変更しないでください。
- コマンドを実行しないでください。
- 短く、初学者にも分かる言葉で整理してください。
""".strip()


# 画面に表示した内容を、保存用のリストにも追加する関数です。
def record_line(output_lines: list[str], text: str) -> None:
    print(text)
    output_lines.append(text)


# AssistantMessageの中から、人が読みやすいテキストやツール名を表示する関数です。
def print_assistant_message(
    message: AssistantMessage,
    output_lines: list[str],
) -> None:
    for block in message.content:
        text = getattr(block, "text", None)
        name = getattr(block, "name", None)

        if text:
            record_line(output_lines, text)
        elif name:
            record_line(output_lines, f"Tool: {name}")


# ResultMessageから、Agentの最終状態を表示する関数です。
def print_result_message(
    message: ResultMessage,
    output_lines: list[str],
) -> None:
    print_section("Result")
    record_line(output_lines, f"Done: {message.subtype}")

    result = getattr(message, "result", None)
    if result:
        record_line(output_lines, str(result))


# Agentの出力をoutputsフォルダに保存する関数です。
def save_output(output_lines: list[str]) -> None:
    OUTPUT_PATH.parent.mkdir(parents=True, exist_ok=True)
    OUTPUT_PATH.write_text("\n".join(output_lines) + "\n", encoding="utf-8")

    print_section("Saved output")
    print(f"Saved: {OUTPUT_PATH}")


# queryを呼び出し、Agentから届くメッセージを順番に処理する関数です。
async def run_agent() -> None:
    options = ClaudeAgentOptions(
        disallowed_tools=["Read", "Glob", "Edit", "Write", "Bash"],
        cwd=str(PROJECT_ROOT),
        max_turns=2,
    )
    prompt = build_prompt()
    output_lines = []

    print_section("Prompt")
    print(prompt)

    print_section("Agent output")
    async for message in query(
        prompt=prompt,
        options=options,
    ):
        if isinstance(message, AssistantMessage):
            print_assistant_message(message, output_lines)
        elif isinstance(message, ResultMessage):
            print_result_message(message, output_lines)

    save_output(output_lines)


# 非同期のrun_agent関数をイベントループで実行する関数です。
def main() -> None:
    asyncio.run(run_agent())


if __name__ == "__main__":
    main()
