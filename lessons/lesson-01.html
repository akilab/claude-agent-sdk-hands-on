Lesson 01 / Foundation

学習前提と公式情報を確認する

このレッスンでは、Agent SDKを動かす前に、契約、認証、Python、uv、作業フォルダの前提を確認します。 最後に、自分の環境を点検するPythonスクリプトを手で書きます。

所要時間 25分
ゴール この教材の前提 公式情報で確認すること Pythonで確認スクリプトを書く 確認問題

Goal

このレッスンのゴール

このレッスンを一言で Agent SDKを始める前に、契約・環境・公式情報を確認し、迷わず学習を進める土台を作ります。

  • Claude Agent SDKが何をするためのSDKか説明できる
  • この教材がPython + uvだけを使う理由を説明できる
  • Pro以上のサブスクリプション前提と、APIキー利用の違いを意識できる
  • 自分の環境を確認するPythonスクリプトを書ける

この教材の前提

仮想環境と依存関係を扱いやすくするため、この教材ではuvに統一します。

Official check

Agent SDKの概要ページでは、Claude Codeのツール、エージェントループ、コンテキスト管理を PythonやTypeScriptから使えることが説明されています。この教材ではPythonだけを扱います。

クイックスタートではPython 3.10+、uvでのセットアップ、`uv init`、`uv add claude-agent-sdk` が紹介されています。次のレッスンで、実際にuvプロジェクトを作ります。

Hands-on

Pythonで確認スクリプトを書く

ここからは手を動かします。`python-labs/practice/lesson_01_check_environment.py` を作り、 次のコードを自分で入力してください。`scripts/` はGit管理対象外なので、学習用に自由に書き換えられます。

python-labs/practice/lesson_01_check_environment.py 
import os
import platform
import shutil
import subprocess
import sys
from pathlib import Path


REQUIRED_PYTHON = (3, 10)
OFFICIAL_DOCS = [
    {
        "title": "Agent SDK の概要",
        "url": "https://code.claude.com/docs/ja/agent-sdk/overview",
    },
    {
        "title": "クイックスタート",
        "url": "https://code.claude.com/docs/ja/agent-sdk/quickstart",
    },
    {
        "title": "Claude プランで Agent SDK を使用する",
        "url": "https://support.claude.com/ja/articles/15036540-claude-%E3%83%97%E3%83%A9%E3%83%B3%E3%81%A7-claude-agent-sdk-%E3%82%92%E4%BD%BF%E7%94%A8%E3%81%99%E3%82%8B",
    },
]


# 見出しを区切り線つきで表示する関数です。
def print_section(title: str) -> None:
    print()
    print("=" * 72)
    print(title)
    print("=" * 72)


# 外部コマンドを実行し、成功したかどうかと出力を返す関数です。
def run_command(command: list[str]) -> tuple[bool, str]:
    try:
        completed = subprocess.run(
            command,
            check=False,
            capture_output=True,
            text=True,
        )
    except FileNotFoundError:
        return False, "command not found"

    output = completed.stdout.strip() or completed.stderr.strip()
    return completed.returncode == 0, output


# Pythonのバージョンが教材の前提を満たしているか確認する関数です。
def check_python_version() -> bool:
    print_section("Python")

    version = sys.version_info
    version_text = platform.python_version()
    print(f"Python version: {version_text}")
    print(f"Python executable: {sys.executable}")

    if version >= REQUIRED_PYTHON:
        print("OK: Python 3.10+ is available.")
        return True
    else:
        print("NG: Python 3.10+ is required for this curriculum.")
        return False


# uvコマンドが使える状態か確認する関数です。
def check_uv() -> bool:
    print_section("uv")

    uv_path = shutil.which("uv")
    if uv_path is None:
        print("NG: uv is not available on PATH.")
        print("Install uv before Lesson 02.")
        return False

    ok, output = run_command(["uv", "--version"])
    print(f"uv path: {uv_path}")
    print(f"uv version: {output if ok else 'could not read version'}")
    return ok


# APIキー環境変数が設定されているかを、値を表示せず確認する関数です。
def check_auth_environment() -> bool:
    print_section("Authentication environment")

    api_key = os.environ.get("ANTHROPIC_API_KEY")
    if api_key:
        print("WARNING: ANTHROPIC_API_KEY is set.")
        print("This may cause API key authentication to be used instead of a Claude plan.")
        print("The actual API key value is intentionally not printed.")
        return False
    else:
        print("OK: ANTHROPIC_API_KEY is not set in this shell.")
        return True


# python-labs配下に必要な学習フォルダがあるか確認する関数です。
def check_project_layout() -> bool:
    print_section("Project layout")

    script_path = Path(__file__).resolve()
    labs_dir = script_path.parents[1]
    expected_dirs = [
        labs_dir / "src" / "agent_sdk_learning",
        labs_dir / "scripts",
        labs_dir / "data",
        labs_dir / "outputs",
    ]

    print(f"python-labs directory: {labs_dir}")

    all_found = True
    for directory in expected_dirs:
        if directory.exists():
            print(f"OK: {directory.name} exists - {directory}")
        else:
            print(f"NG: missing directory - {directory}")
            all_found = False

    return all_found


# この教材で確認する公式ドキュメントの一覧を表示する関数です。
def show_official_docs() -> None:
    print_section("Official documentation to check")

    for index, doc in enumerate(OFFICIAL_DOCS, start=1):
        print(f"{index}. {doc['title']}")
        print(f"   {doc['url']}")


# 各確認結果をOKまたは要確認としてまとめて表示する関数です。
def print_summary(results: dict[str, bool]) -> None:
    print_section("Summary")

    for name, ok in results.items():
        status = "OK" if ok else "要確認"
        print(f"{name}: {status}")


# Lesson 01の確認処理を順番に実行する関数です。
def main() -> None:
    print("Claude Agent SDK Hands-on / Lesson 01")
    results = {
        "Python 3.10+": check_python_version(),
        "uv": check_uv(),
        "Authentication environment": check_auth_environment(),
        "Project layout": check_project_layout(),
    }
    show_official_docs()
    print_summary(results)


if __name__ == "__main__":
    main()

Review

確認問題

  1. この教材でNode.jsとTypeScriptを扱わない理由を、自分の言葉で1文にしてください。
  2. `ANTHROPIC_API_KEY` が設定されていると、なぜ注意が必要ですか。
  3. `ANTHROPIC_API_KEY` の値そのものを表示してはいけない理由は何ですか。
  4. Python 3.10+ とuvのどちらが不足しているか、確認スクリプトの出力から判断してください。
  5. Lesson 01でまだAgent SDKを呼び出さない理由は何ですか。
