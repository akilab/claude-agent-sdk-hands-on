Lesson 20 / ClaudeSDKClient

会話メッセージをSQLiteへ保存する

既存ユーザーがClaudeと1回やり取りし、その会話をSQLiteへ保存します。 今回はセッション選択や過去会話の再開には進まず、`sessions` と `messages` の関係を見える形で作ります。

所要時間 60分
ゴール 実行前の確認 保存モデル 処理の流れ 初登場の関数 完成コードを読む 実行して確認 DB Browserで確認 確認問題

Goal

このレッスンのゴール

このレッスンを一言で Claudeとの1回の会話を、`sessions` と `messages` に分けてSQLiteへ保存します。

  • 既存ユーザー `learner-001` の会話として保存できる
  • `ResultMessage.session_id` を `sessions.claude_session_id` に保存できる
  • ユーザー入力とClaudeの返答を `messages` に保存できる
  • DB Browserで、1つのセッションに複数メッセージが紐づくことを確認できる

Before run

先にユーザーをDBへ入れておく

今回は「ユーザーは先に作られている」前提で進めます。 Lesson 19を実行して、`users` テーブルに `learner-001` が入っている状態にしてください。 まだの場合は、次を先に実行します。

Windows / macOS / Linux 
uv run python scripts/lesson_19_import_registry_to_sqlite.py
DB処理はshared.databaseにあります

Lesson 20では、`connect_database()`、`create_schema()`、`insert_session_if_missing()`、`insert_message()` などを使います。 これらはSQLの細部をまとめた共通部品です。 ただし、どのタイミングで `sessions` に入れ、どのタイミングで `messages` に入れるかは、このレッスンのコード側で見えるようにしています。

以前のLesson 20を実行していた場合

以前の版では `messages.role = "result"` も保存していました。 今回から `messages` は `user` と `assistant` の会話本文に絞ります。 DB Browserで古い `result` 行が残っていて気になる場合は、DB Browserを閉じてから `data/agent_sessions.sqlite3` を削除し、Lesson 18、19、20の順に実行し直してください。

Model

保存するデータの形

1回のClaudeとのやり取りは、1つのセッションと複数のメッセージに分けて保存します。 `sessions` は会話の箱、`messages` はその箱に入る発言です。

保存先 入れる値 意味
sessions.claude_session_id ResultMessage.session_id Claude側の会話ID
messages.role = "user" PROMPT ユーザーが送った入力
messages.role = "assistant" AssistantMessage.content Claudeが返した本文
ResultMessageはmessagesには保存しません

Claudeの返答本文は主に `AssistantMessage` から取ります。 `ResultMessage` は `session_id`、成功/失敗、turn数などを得るために使います。 会話履歴として保存する本文は `user` と `assistant` に絞り、`ResultMessage.result` はこのレッスンではDBへ保存しません。

Sequence

処理の順番を見る

先に `client.query(PROMPT)` でClaudeへ入力を送り、`receive_response()` で `AssistantMessage` と `ResultMessage` を受け取ります。 そのあと、`ResultMessage.session_id` を使って `sessions` を作り、同じIDで `messages` を紐づけます。

API

初めて出てくる関数

名前 種類 役割
require_user_exists(connection, user_id) 共通関数 DBに対象ユーザーが存在するか確認します。なければ分かりやすいエラーを出します。
insert_message(...) 共通関数 `messages` テーブルに1行追加します。引数は `session_id`、`role`、`content`、`turn_number`、`created_at` です。
collect_assistant_text(message) このレッスンの関数 `AssistantMessage.content` から、DBへ保存するテキスト本文だけを集めます。
save_conversation_to_database(...) このレッスンの関数 1回のAgent実行結果を `sessions` と `messages` に保存する中心処理です。

Hands-on

完成コードを読む

`python-labs/scripts/lesson_20_save_messages_to_sqlite.py` の完成コードを確認します。 長く見えますが、中心は `run_agent()` で受け取った結果を `save_conversation_to_database()` に渡す流れです。

python-labs/scripts/lesson_20_save_messages_to_sqlite.py 
import asyncio
from datetime import datetime, timezone

from claude_agent_sdk import (
    AssistantMessage,
    ClaudeAgentOptions,
    ClaudeSDKClient,
    ResultMessage,
)

from shared.database import (
    connect_database,
    count_rows,
    create_schema,
    fetch_message_summary,
    insert_message,
    insert_session_if_missing,
    require_user_exists,
)
from shared.display import print_section
from shared.messages import print_assistant_message
from shared.paths import PROJECT_ROOT


USER_ID = "learner-001"
CONVERSATION_TITLE = "ClaudeSDKClient message persistence"
PROMPT = (
    "ClaudeSDKClientで会話メッセージをDBに保存する理由を、"
    "Webアプリ開発者向けに3文で説明してください。"
)


# UTCの現在時刻を、SQLiteに保存しやすい文字列にする関数です。
def now_iso() -> str:
    return datetime.now(timezone.utc).isoformat()


# ClaudeSDKClientに渡す実行設定を作る関数です。
def build_options() -> ClaudeAgentOptions:
    return ClaudeAgentOptions(
        cwd=str(PROJECT_ROOT),
        system_prompt=(
            "あなたはClaude Agent SDKを学ぶ日本語教材の補助者です。"
            "短く、Webアプリ開発の文脈に結びつけて説明してください。"
        ),
        disallowed_tools=["Read", "Glob", "Grep", "Write", "Edit", "Bash"],
        max_turns=2,
    )


# AssistantMessage.contentの各ブロックから、表示できるテキストを取り出す関数です。
def collect_assistant_text(message: AssistantMessage) -> str:
    text_parts: list[str] = []

    for block in message.content:
        text = getattr(block, "text", None)
        if text:
            text_parts.append(str(text))

    return "\n".join(text_parts)


# Agentからの1回分の応答を最後まで読み、本文とResultMessageを返す関数です。
async def receive_response(client: ClaudeSDKClient):
    result_message: ResultMessage | None = None
    assistant_texts: list[str] = []

    async for message in client.receive_response():
        if isinstance(message, AssistantMessage):
            text = collect_assistant_text(message)
            if text:
                assistant_texts.append(text)
            print_assistant_message(message)
        elif isinstance(message, ResultMessage):
            result_message = message

    if result_message is None:
        raise RuntimeError("ResultMessageを受け取れなかったため、DBへ保存できません。")

    return "\n\n".join(assistant_texts), result_message


# ClaudeSDKClientで1回問い合わせ、会話本文とsession_idを含む結果を受け取る関数です。
async def run_agent():
    async with ClaudeSDKClient(options=build_options()) as client:
        await client.query(PROMPT)
        return await receive_response(client)


# ResultMessageから、sessionsテーブルに登録する1会話分の辞書を作る関数です。
def build_session_record(result_message: ResultMessage) -> dict[str, str]:
    timestamp = now_iso()

    return {
        "session_id": result_message.session_id,
        "title": CONVERSATION_TITLE,
        "cwd": str(PROJECT_ROOT),
        "created_at": timestamp,
        "updated_at": timestamp,
    }


# 1回のAgent実行結果を、sessionsとmessagesへ保存する関数です。
def save_conversation_to_database(
    user_prompt: str,
    assistant_text: str,
    result_message: ResultMessage,
) -> None:
    session_record = build_session_record(result_message)
    claude_session_id = session_record["session_id"]

    with connect_database() as connection:
        create_schema(connection)
        require_user_exists(connection, USER_ID)

        insert_session_if_missing(connection, USER_ID, session_record)
        insert_message(connection, claude_session_id, "user", user_prompt, 1, now_iso())
        insert_message(connection, claude_session_id, "assistant", assistant_text, 2, now_iso())

        connection.commit()

        print_section("Saved to database")
        print(f"user_id: {USER_ID}")
        print(f"session_id: {claude_session_id}")
        print(f"result_subtype: {result_message.subtype}")
        print(f"num_turns: {result_message.num_turns}")
        print(f"sessions: {count_rows(connection, 'sessions')}")
        print(f"messages: {count_rows(connection, 'messages')}")

        print_section("Saved messages")
        for message in fetch_message_summary(connection, claude_session_id):
            print(f"- turn {message['turn_number']} / {message['role']}: {message['preview']}")


# 新しい会話を実行し、結果をSQLiteへ保存する全体の流れをまとめる関数です。
async def create_conversation_and_save_messages() -> None:
    print_section("Prompt")
    print(PROMPT)

    assistant_text, result_message = await run_agent()
    save_conversation_to_database(PROMPT, assistant_text, result_message)


# このファイルを直接実行したときの入口になる関数です。
def main() -> None:
    asyncio.run(create_conversation_and_save_messages())


if __name__ == "__main__":
    main()

DB Browser

DB Browserで確認

DB Browser for SQLiteで `python-labs/data/agent_sessions.sqlite3` を開きます。 `messages` テーブルを表示し、`claude_session_id`、`role`、`content`、`turn_number` を確認してください。

同じ `claude_session_id` の行が2件あり、`role` が `user` と `assistant` になっていれば成功です。 `ResultMessage` は `sessions` を作るための `session_id` と実行メタ情報として使い、会話本文としては保存しません。

Review

確認問題

  1. `sessions` と `messages` を分けて保存する理由は何ですか。
  2. `AssistantMessage` と `ResultMessage` は、それぞれ何を保存するために使いましたか。
  3. `require_user_exists()` は、なぜ `insert_user_if_missing()` ではなく確認だけにしているのですか。
  4. `messages.claude_session_id` は、どのテーブルのどの値と対応しますか。
  5. `ResultMessage.result` を `messages` に保存しない理由は何ですか。
