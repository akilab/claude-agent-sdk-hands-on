Lesson 14 / ClaudeSDKClient

ClaudeSDKClientの最小会話を動かす

`ClaudeSDKClient` を使い、同じclientインスタンスに2回問い合わせます。 `client.query()` は送信、`client.receive_response()` は受信という役割分担を、短いコードで確認します。

所要時間 55分
ゴール 実行前の確認 初出APIの見方 処理の流れ コードを書く 実行して確認 確認問題

Goal

このレッスンのゴール

このレッスンを一言で `ClaudeSDKClient` で同じ会話を続ける最小形を作り、送信と受信の分離を理解します。

  • `async with ClaudeSDKClient(...) as client` の役割を説明できる
  • `client.query()` はプロンプト送信、`client.receive_response()` は応答受信だと説明できる
  • 同じclientで2回問い合わせると、同じセッションの文脈を引き継ぐことを確認できる
  • `ResultMessage.session_id` を見て、会話の識別子を観察できる

Before run

実行前の確認

このレッスンでは実際にClaudeへ問い合わせます。 Pro以上のサブスクリプションでClaude Code / Agent SDKを使える状態にしてから進めてください。 契約条件や利用枠は変更される可能性があるため、実務利用前には公式情報を確認します。

今回もツールは使いません

目的はファイル操作やコード編集ではなく、同じclientで会話が続く感覚をつかむことです。 `disallowed_tools` で主要ツールを使わないようにし、会話の流れだけを観察します。

SDK concepts

初めて出てくる関数・クラス・メソッド

`ClaudeSDKClient` は、単発の `query()` とは使い方が少し違います。 まず「何がクラスで、何がメソッドか」を分けて見ます。

名前 分類 引数 戻り値・読み方 このコードでの役割
ClaudeSDKClient クラス options など clientインスタンスを作る 同じセッションを保ったまま、複数回の問い合わせを送る入口。
async with ClaudeSDKClient(...) 非同期コンテキストマネージャー 生成済みclientを as client で受ける ブロックを抜けるとclientを閉じる 会話の開始と終了をコード上で明示する。
client.query(prompt) メソッド 文字列、またはメッセージストリーム 応答本文を直接返すのではなく、問い合わせをclientへ送る 1回目、2回目のプロンプトを同じclientへ送る。
client.receive_response() メソッド なし 非同期イテレータ。AssistantMessage や ResultMessage を順に返す 直前に送った問い合わせの応答を最後まで読む。
ResultMessage.session_id 属性 なし SDKが付けたセッションID文字列 1回目と2回目が同じ会話として扱われているかを観察する。
`client.query()` だけでは応答を読みません

`query()` 関数版では async for message in query(...) と書きました。 `ClaudeSDKClient` では await client.query(...) で送信し、 その後に async for message in client.receive_response() で応答を読みます。

セッションの操作 Python SDK reference

Sequence

処理の流れ

ポイントは、clientを1つ作り、その中で「送る」「読む」を2回繰り返すことです。 `options` は設定であり、会話を進める主体は `client` です。

Hands-on

コードを書く

`python-labs/practice/lesson_14_client_minimal_conversation.py` に、次のコードを入力してください。 関数ごとの役割が見えるように、今回は少しコメントを多めにしています。

python-labs/practice/lesson_14_client_minimal_conversation.py 
import asyncio

from claude_agent_sdk import (
    AssistantMessage,
    ClaudeAgentOptions,
    ClaudeSDKClient,
    ResultMessage,
)

from shared.display import print_section, record_line
from shared.files import write_text_lines
from shared.messages import append_result_message, print_assistant_message
from shared.paths import OUTPUT_DIR


PROMPTS = [
    (
        "1回目の質問",
        "PythonでAgent SDKを学ぶ人に向けて、ClaudeSDKClientを一文で説明してください。",
    ),
    (
        "2回目の質問",
        "先ほどの説明を前提に、query()との違いを二つの箇条書きで説明してください。",
    ),
]

OUTPUT_PATH = OUTPUT_DIR / "lesson_14_client_conversation.txt"


# ClaudeSDKClientに渡す実行設定を作る関数です。
def build_options() -> ClaudeAgentOptions:
    return ClaudeAgentOptions(
        system_prompt=(
            "あなたはClaude Agent SDKを学ぶ日本語教材の補助者です。"
            "短く、具体的に、初学者にも分かる言葉で答えてください。"
        ),
        disallowed_tools=["Read", "Glob", "Grep", "Write", "Edit", "Bash"],
        max_turns=2,
    )


# 1回分の問い合わせに対するメッセージを最後まで読む関数です。
async def receive_current_response(
    client: ClaudeSDKClient,
    label: str,
) -> tuple[ResultMessage | None, list[str]]:
    result_message = None
    output_lines: list[str] = []

    record_line(output_lines, "=" * 72)
    record_line(output_lines, label)
    record_line(output_lines, "=" * 72)

    async for message in client.receive_response():
        if isinstance(message, AssistantMessage):
            print_assistant_message(message, output_lines)
        elif isinstance(message, ResultMessage):
            result_message = message
            append_result_message(message, output_lines, include_result=False)

    print("\n".join(output_lines))
    return result_message, output_lines


# 同じClaudeSDKClientで2回問い合わせ、同じセッションが続くことを確認する関数です。
async def run_conversation() -> None:
    options = build_options()
    session_ids: list[str] = []
    conversation_lines: list[str] = []

    print_section("ClaudeSDKClient conversation")

    async with ClaudeSDKClient(options=options) as client:
        for label, prompt in PROMPTS:
            print_section(label)
            print(prompt)

            await client.query(prompt)
            result_message, response_lines = await receive_current_response(client, label)
            conversation_lines.extend(response_lines)
            conversation_lines.append("")

            if result_message is not None:
                session_ids.append(result_message.session_id)

    output_lines = [
        "ClaudeSDKClient conversation summary",
        "",
        "Observed session IDs:",
        *session_ids,
        "",
        "If the same client continued the conversation, the session IDs should match.",
        "",
        "Conversation output:",
        *conversation_lines,
    ]
    write_text_lines(OUTPUT_PATH, output_lines)

    print_section("Saved")
    print(OUTPUT_PATH)


# このファイルを直接実行したときの入口になる関数です。
def main() -> None:
    asyncio.run(run_conversation())


if __name__ == "__main__":
    main()

session_idの見方

出力ファイルには、各問い合わせの `ResultMessage.session_id` を保存しています。 同じclientで会話を続けている場合、1回目と2回目は同じセッションとして扱われます。 ここではIDそのものを暗記する必要はなく、「後でresumeするときの会話識別子」として見てください。
