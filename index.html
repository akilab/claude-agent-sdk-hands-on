Python + uv hands-on portal

Pythonを動かしながら、Agent SDKを理解する。

Claude Agent SDKを、Pythonとuvだけに絞って学ぶための学習ポータルです。 完成コードを実行して動作を観察し、気になった部分のソースを読みながら、Pythonの基本、SDKの流れ、Skills、サブエージェント、ClaudeSDKClientまで段階的に進めます。

学習ロードマップを見る 公式ドキュメントを確認
環境 Python + uv のみ

Pythonの書き方とuvでの実行を、教材全体の共通前提にします。

形式 動かして理解する

各レッスンで完成コードを実行し、動作を見てから必要な部分だけ読みます。

Current curriculum status

Pythonだけで、基礎からSkillsとサブエージェントまで。

学習内容を「Python学習編」「Claude Agent SDK 基本」「ClaudeSDKClient編」の3セクションに分けました。 すべての章で、まず完成コードを動かし、結果を確認してからソースを読む流れにします。

Learning roadmap

学習ロードマップ

Pythonの基礎を補いながら、Agent SDKの実行、制御、拡張、役割分担へ進みます。

  1. 01

    前提を整える

    Pro以上の契約、uv、Python 3.10+、APIキーとの違いを確認します。

  2. 02

    Pythonを動かして読む

    変数、関数、辞書、リスト、例外処理を小さな完成コードで確認します。

  3. 03

    最小Agentを動かす

    uvでSDKを追加し、`query()` と `async for` の基本を実行します。

  4. 04

    出力と権限を扱う

    メッセージ、結果、ツール許可、承認の考え方をコードで確認します。

  5. 05

    Skillsで拡張する

    繰り返し使う手順や判断をSkillとして切り出す考え方を学びます。

  6. 06

    サブエージェント化する

    調査、実装、レビューの役割を分け、業務向けの体制にします。

  7. 07

    会話を継続する

    ClaudeSDKClientで、継続会話、セッション管理、ストリーミングを学びます。
